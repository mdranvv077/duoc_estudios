Episodio 02 · Módulo 02

De la tabla a Python.

Crear un array de dos dimensiones y traducir correctamente las posiciones matemáticas.

Importar la herramienta

El formulario utiliza import numpy as np. NumPy permite trabajar con arrays numéricos; para representar nuestras matrices usaremos arrays de dos dimensiones. El alias np es un nombre corto para acceder a la librería.

Cada lista interior representa una fila. Todas deben tener la misma cantidad de elementos. Las comas separan datos; el punto separa los decimales. No copies 2,6 como si fuera el decimal 2,6: Python lo leería como dos valores.

Python · Crear una matriz y consultar su orden
import numpy as np

A = np.array([
    [12, 8, 15],
    [10, 14, 9]
])
print(A)
print(A.shape)
print(A.size)

Resultado esperado
[[12  8 15]
 [10 14  9]]
(2, 3)
6

A.shape devuelve (filas, columnas). A.size cuenta todos los elementos. No se escriben paréntesis después de shape: es una propiedad, no una función.

Las posiciones empiezan en 0

Primero en la matriz: para encontrar a23, sitúate en la segunda fila y avanza hasta su tercera columna. No sumes ni multipliques los subíndices: son coordenadas. Para que exista aij en una matriz m × n, necesitamos 1 ≤ i ≤ m y 1 ≤ j ≤ n.

Después en Python: traduce esas coordenadas restando uno a cada una. El significado de la fila y la columna se conserva; cambia la numeración que utiliza el programa.

aij en matemática → A[i − 1, j − 1] en Python
MatemáticaPythonUbicación
a₁₁A[0, 0]Primera fila, primera columna.
a₂₃A[1, 2]Segunda fila, tercera columna.
Toda la fila 2A[1, :]Los dos puntos indican todas las columnas.
Toda la columna 3A[:, 2]Los dos puntos indican todas las filas.
Python · Leer un elemento, una fila y una columna
import numpy as np

A = np.array([[12, 8, 15], [10, 14, 9]])
print(A[1, 2])
print(A[1, :])
print(A[:, 2])

Resultado esperado
9
[10 14  9]
[15  9]

El dato pedido no cambia por usar índices desde cero: sigue siendo el producto 2 en la región 3. Solo cambia la forma de señalarlo en el código. No escribas A[2, 3] para a23: en esta matriz estarías fuera de sus límites.

Una lista no opera igual que un array

Python · Sumar listas frente a sumar arrays
import numpy as np

lista = [1, 2]
print(lista + lista)
A = np.array([[1, 2]])
print(A + A)

Resultado esperado
[1, 2, 1, 2]
[[2 4]]

El + entre listas concatena: une los elementos. Entre arrays compatibles suma sus valores por posición. Por eso conviene conservar np.array al adaptar el formulario, en vez de dejar solamente listas.

Cómo interpretar lo que sale

Antes de ejecutarlo: predice qué devolverán A[0, 1] y A[:, 0] en el ejemplo inicial. Escríbelo primero desde la tabla; luego modifica el código y comprueba tu respuesta. Debes obtener 8 y la columna formada por 12 y 10. Así practicas tanto la lectura como la escritura del código.

Si Python imprime 9, completa la respuesta con fila, columna y unidad. Si imprime (2, 3), responde “dos filas y tres columnas”, no “la matriz vale dos y tres”. El resultado del programa y la explicación del problema cumplen papeles diferentes.

En Colab. Ejecuta la importación y la definición de A antes de consultarla. Para evitar depender de otra celda, los ejemplos de esta categoría incluyen sus propios datos e importación.
¿Cómo leerías a₃₄ en una matriz de tres filas y cuatro columnas?

Con A[2, 3]. Restas uno a ambos subíndices, no solo al de la fila.
