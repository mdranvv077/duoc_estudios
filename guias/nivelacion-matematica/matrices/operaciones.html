Episodio 02 · Módulo 03

Sumar datos que sí se corresponden.

La dimensión tiene que coincidir, pero también el significado de cada posición.

Una operación por casilla

Para sumar matrices, sumamos elementos de la misma posición. Para restarlas, hacemos lo mismo respetando el orden de la resta. En G5, A contiene el primer año y B el segundo, con los mismos productos, regiones y unidades.

sij = aij + bij   ·   dij = bij − aij

A + B reúne las ventas de ambos años. B − A expresa cuánto cambió el segundo respecto del primero: un número positivo indica aumento y uno negativo disminución. No tiene el mismo significado que A − B.

Resolver una matriz pequeña a mano

Antes de usar los datos grandes de G5, toma A y B de orden 2 × 2. No combinamos una fila de A con una columna de B: sumamos o restamos las casillas que ocupan la misma posición.

Reconstruye cada resultado conservando esas posiciones: S tiene filas (6, 3) y (5, 10); D tiene filas (4, −1) y (−1, 2). Ambas siguen siendo 2 × 2. Un resultado negativo es válido: en un contexto de variaciones expresa una disminución.

Propiedades que ayudan a comprobar: A + B = B + A, pero en general B − A no es A − B. Además, A − A es la matriz cero del mismo orden. Cambiar el orden de la resta cambia los signos, no las posiciones.

La misma operación en Python

Escribe las dos matrices pequeñas con np.array y calcula S = A + B y D = B - A. Comprueba las cuatro casillas anteriores antes de pasar a G5. En el siguiente ejemplo la instrucción es la misma; solo aumentan los datos.

Python · G5 · Ventas de dos años
import numpy as np

A = np.array([
    [2.6, 4.8, 1.8, 0.9],
    [3.2, 4.4, 2.5, 2.8],
    [2.4, 3.6, 3.8, 2.5]
])
B = np.array([
    [3.6, 2.5, 3.0, 2.5],
    [4.5, 5.0, 3.5, 3.8],
    [2.9, 3.0, 4.6, 4.0]
])
S = A + B
D = B - A
print("S:")
print(np.round(S, 2))
print("D:")
print(np.round(D, 2))
print("s24:", round(float(S[1, 3]), 2))
print("d24:", round(float(D[1, 3]), 2))

s24 = 6,6: el producto 2 acumuló 6,6 millones de dólares en la región 4 durante los dos años. d24 = 1: sus ventas aumentaron un millón de dólares del primer al segundo año. Esa diferencia es un monto, no un porcentaje.

Cuándo no se puede sumar

Si el tercer año incorpora seis regiones, E tiene orden 3 × 6. No podemos sumar directamente A + B + E con A y B de orden 3 × 4. Faltan posiciones que se correspondan. Además, ni siquiera igualar dimensiones basta si se cambió el orden de las regiones.

Una precaución de Python. NumPy admite ciertos cálculos entre formas diferentes mediante broadcasting. Eso no significa que toda suma matricial esté definida. En estos ejercicios exige igual shape y revisa que filas, columnas y unidades representen lo mismo.

Un total por modelo no es otra matriz de componentes

En el problema 2, las filas son los cinco modelos y las columnas los tres componentes. Primero J + C combina ambas sucursales por componente. Para obtener un costo total por modelo, además hay que sumar las tres columnas de cada fila.

A mano, para el modelo 1: (100 + 110) + (200 + 190) + (150 + 160) = 210 + 390 + 310 = 910. Hemos hecho dos operaciones: reunir sucursales y sumar componentes. En Python, esas dos ideas se escriben como total = J + C y total.sum(axis=1).

Python · G5 · Costos por modelo
import numpy as np

J = np.array([
    [100, 200, 150], [120, 210, 170],
    [112, 200, 131], [124, 310, 170],
    [136, 156, 140]
])
C = np.array([
    [110, 190, 160], [130, 220, 180],
    [146, 190, 141], [143, 312, 163],
    [137, 116, 156]
])
total = J + C
print("Total por modelo:")
print(total.sum(axis=1))
print("Japón, modelo 4, componente 3:", J[3, 2])
print("China, modelo 4, componente 3:", C[3, 2])

Resultado esperado
Total por modelo:
[ 910 1030  920 1222  841]
Japón, modelo 4, componente 3: 170
China, modelo 4, componente 3: 163

axis=1 suma a través de las columnas y deja un resultado por fila. axis=0 suma a través de las filas y deja un resultado por columna. Aquí los totales están en miles de dólares. Para el modelo 4, componente 3, Japón registra 170 y China 163: Japón supera a China en 7 mil dólares.

¿Qué significan j₂₁ y c₁₂ en este problema?

j₂₁ = 120: costo mensual del componente 1 para el modelo 2 en Japón, en miles de dólares. c₁₂ = 190: componente 2 para el modelo 1 en China, en la misma unidad. No intercambies modelo y componente.
