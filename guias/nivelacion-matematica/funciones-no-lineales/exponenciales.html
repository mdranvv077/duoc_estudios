Funciones exponenciales.

En un modelo exponencial, la variable aparece en el exponente. El cambio se calcula sobre el valor que ya se había acumulado.

Sumar lo mismo no es crecer al mismo porcentaje

Una función lineal puede sumar 100 personas cada año. Una función exponencial puede aumentar, por ejemplo, un 3 % de la población existente: cuanto mayor es la población, mayor es también el aumento siguiente.

P(t) = P₀ · ektP₀ es el valor inicial y k controla la rapidez y el sentido del cambio.
  • Si k > 0, existe crecimiento exponencial.
  • Si k < 0, existe disminución o decaimiento exponencial.
  • Si t = 0, entonces P(0) = P₀.

Ejemplo de crecimiento

Supongamos que una plataforma comienza con 1.000 usuarios y su crecimiento se aproxima mediante U(t) = 1000e0,03t, donde t representa años desde el inicio.

Python · código
import numpy as np
from scipy.optimize import fsolve

def usuarios(t):
    return 1000 * np.exp(0.03 * t)

usuarios_10 = usuarios(10)
tiempo_2000 = fsolve(lambda t: usuarios(t) - 2000, 20)[0]

print(usuarios_10)
print(tiempo_2000)

La primera operación evalúa el modelo después de 10 años. La segunda busca cuándo la salida llega a 2.000; nuevamente restamos el objetivo para que fsolve encuentre un cero.

El peligro de extrapolar

Un crecimiento exponencial puede producir cifras enormes fuera del período observado. Que Python pueda calcularlas no significa que el modelo siga siendo realista: pueden aparecer límites de recursos, cambios en la tasa o condiciones nuevas.

Dominio contextual: si los datos se estudiaron entre 1960 y 2023, una estimación para el año 2200 requiere una justificación especial. El modelo no obtiene validez ilimitada solo por tener una fórmula.
