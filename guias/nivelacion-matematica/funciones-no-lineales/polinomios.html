Funciones polinómicas.

Las funciones lineales y cuadráticas pertenecen a una familia mayor: los polinomios. Reconocer su grado ayuda a anticipar su comportamiento.

Qué es un polinomio

Un polinomio suma términos formados por números y potencias enteras no negativas de la variable. Su grado corresponde al exponente más alto cuyo coeficiente no sea cero.

ExpresiónGradoNombre habitual
3x + 21Lineal
−2x² + 5x2Cuadrática
x³ − 4x3Cúbica
0,1x⁴ − 2x² + 34Cuártica

Una función de grado mayor puede cambiar de dirección varias veces y cortar el eje x en varios puntos. Eso no significa que siempre lo hará: sus coeficientes también influyen.

Graficar antes de concluir

Para una primera exploración conviene observar la curva y luego calcular los valores importantes. El siguiente ejemplo compara una cúbica y una cuártica en el mismo dominio.

Python · código
import numpy as np
import matplotlib.pyplot as plt

def cubica(x):
    return x**3 - 4 * x

def cuartica(x):
    return 0.1 * x**4 - 2 * x**2 + 3

x = np.linspace(-4, 4, 300)
plt.plot(x, cubica(x), label="Cúbica")
plt.plot(x, cuartica(x), label="Cuártica")
plt.axhline(0, color="gray")
plt.legend()
plt.grid()
plt.show()

Raíces mediante sus coeficientes

np.roots recibe los coeficientes ordenados desde la potencia mayor hasta el término independiente. Para x³ − 4x, también debemos escribir el coeficiente cero de x² y el término independiente cero.

Python · código
raices = np.roots([1, 0, -4, 0])
print(raices)
Al interpretar: una raíz puede ser real o compleja. En un problema contextual, normalmente buscamos soluciones reales que además pertenezcan al dominio indicado.
