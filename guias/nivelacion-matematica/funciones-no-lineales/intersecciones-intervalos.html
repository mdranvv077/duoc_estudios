Módulo 04

Intersecciones e intervalos.

Comparar dos funciones permite encontrar cuándo entregan el mismo resultado y durante qué intervalo una supera a la otra.

Igualar los modelos

Consideremos h(x) = 2(x − 2)² e i(x) = x + 1. Una intersección ocurre cuando ambas salidas son iguales:

h(x) = i(x)Es equivalente a buscar dónde h(x) − i(x) = 0.

La resta es importante porque fsolve busca ceros. Como puede existir más de una solución, usamos distintos valores iniciales cercanos a cada cruce observado en el gráfico.

Python · código
from scipy.optimize import fsolve

def h(x):
    return 2 * (x - 2)**2

def i(x):
    return x + 1

cruce_1 = fsolve(lambda x: h(x) - i(x), 1)[0]
cruce_2 = fsolve(lambda x: h(x) - i(x), 4)[0]

print(cruce_1, h(cruce_1))
print(cruce_2, h(cruce_2))
Resultado
1.0 2.0
3.5 4.5

¿Qué ocurre entre los cruces?

Los puntos de intersección separan el dominio en intervalos. Podemos probar un valor dentro de cada uno y comparar las salidas. Por ejemplo, en x = 2, h(2) = 0 e i(2) = 3; por lo tanto, entre 1 y 3,5 la función h se encuentra debajo de i.

IntervaloRelación
x < 1h(x) > i(x)
1 ≤ x ≤ 3,5h(x) ≤ i(x)
x > 3,5h(x) > i(x)
Antes de aceptar un intervalo: compáralo con el dominio contextual. Si el problema solo admite valores entre 0 y 3, la parte posterior a 3 no debe incluirse en la respuesta.
