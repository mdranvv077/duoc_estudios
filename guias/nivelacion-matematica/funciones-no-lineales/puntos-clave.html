Módulo 03

Puntos clave de una parábola.

Las raíces, el vértice y el intercepto permiten explicar una función cuadrática sin describir cada punto del gráfico.

Tres elementos que conviene buscar

ElementoQué significaPregunta contextual
RaícesValores de x donde f(x) = 0.¿Cuándo llega la altura a cero?
VérticePunto máximo o mínimo de la parábola.¿Cuándo alcanza la altura máxima?
Intercepto en yValor f(0), representado por c.¿Cuál era el valor inicial?

Aplicarlo a la altura

Retomemos h(t) = −25t² + 100t. Su eje de simetría y la entrada del vértice se calculan con:

t = −b / (2a) = −100 / (2 · −25) = 2El objeto alcanza su altura máxima a los 2 segundos.

Al evaluar h(2), obtenemos 100 metros. Las raíces son 0 y 4: representan el inicio del movimiento y el momento en que vuelve a la altura cero.

Python · código
import numpy as np

def altura(t):
    return -25 * t**2 + 100 * t

a = -25
b = 100
c = 0

raices = np.roots([a, b, c])
tiempo_vertice = -b / (2 * a)
altura_maxima = altura(tiempo_vertice)

print(f"Raíces: {raices}")
print(f"Máximo: {altura_maxima} m a los {tiempo_vertice} s")
Resultado
Raíces: [4. 0.]
Máximo: 100.0 m a los 2.0 s

El contexto filtra las respuestas

Una ecuación puede entregar soluciones matemáticamente correctas que no sirven en el problema. Un tiempo negativo, una cantidad fraccionaria de personas o un valor posterior al intervalo observado debe revisarse antes de comunicarlo.

Buena práctica: escribe siempre la respuesta con unidades y significado. “El vértice es (2, 100)” informa menos que “a los 2 segundos se alcanza una altura máxima de 100 metros”.
