Módulo 02

Funciones cuadráticas.

Una función cuadrática contiene una variable elevada al cuadrado. Su gráfico es una parábola y permite representar procesos que cambian de dirección.

La forma general

f(x) = ax² + bx + ca debe ser distinto de 0
aControla la apertura y la orientación de la parábola.
bAyuda a determinar dónde se ubican su eje y su punto máximo o mínimo.
cEs el valor de f(0): el punto donde el gráfico corta el eje y.

Si a es positivo, la parábola abre hacia arriba y posee un mínimo. Si es negativo, abre hacia abajo y posee un máximo. Cuanto mayor es el valor absoluto de a, más cerrada se observa.

Ejemplo: altura de un objeto

La función h(t) = −25t² + 100t puede representar la altura de un objeto durante algunos segundos. La variable independiente t es el tiempo y h(t) es la altura.

  • Al comienzo, el objeto se encuentra en h(0) = 0.
  • La altura aumenta, pero no de manera constante.
  • Alcanza un punto máximo y luego disminuye.
Python · código
import numpy as np
import matplotlib.pyplot as plt

def altura(t):
    return -25 * t**2 + 100 * t

tiempo = np.linspace(0, 4, 100)
plt.plot(tiempo, altura(tiempo))
plt.xlabel("Tiempo (s)")
plt.ylabel("Altura (m)")
plt.grid()
plt.show()

np.linspace(0, 4, 100) crea 100 valores entre 0 y 4 para dibujar una curva suave. Ese intervalo también evita interpretar tiempos anteriores al lanzamiento o posteriores a la caída.

No confundas los coeficientes: en −25t² + 100t, el coeficiente cuadrático es −25, el coeficiente lineal es 100 y el término independiente es 0.
