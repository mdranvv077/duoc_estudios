Módulo 07

Funciones con raíz cuadrada.

Estos modelos suelen crecer con rapidez al comienzo y cada vez más lentamente. Su dominio necesita una atención especial.

La restricción nace dentro de la raíz

En los números reales no podemos calcular la raíz cuadrada de un valor negativo. Por eso, en f(x) = a√x + b se requiere x ≥ 0. Si aparece √(x − 4), entonces necesitamos x ≥ 4.

Dos revisiones del dominioPrimero revisa qué permite la fórmula; después, qué permite la situación real.

Aunque la fórmula acepte x = 2,5, un contexto donde x representa servidores completos puede exigir valores enteros.

Ejemplo: consumo energético

El modelo E(x) = 200√x + 500 estima el consumo de energía según la cantidad x de servidores activos. Los 500 representan un consumo base y la raíz modela un aumento que se hace menos pronunciado.

Python · código
import numpy as np
from scipy.optimize import fsolve

def energia(servidores):
    return 200 * np.sqrt(servidores) + 500

consumo_25 = energia(25)
limite = fsolve(lambda x: energia(x) - 1900, 40)[0]

print(consumo_25)
print(limite)
Resultado
1500.0
49.0

Con 25 servidores, el consumo estimado es 1.500 unidades. El modelo llega a 1.900 con 49 servidores; si ese valor es el máximo permitido, 49 es el límite que no se debe superar.

Cómo se ve su crecimiento

Entre 0 y 1, la raíz aumenta una unidad. Entre 100 y 101, aumenta muy poco. La función continúa creciendo, pero cada nueva unidad de entrada aporta un cambio menor que al inicio.

Antes de usar np.sqrt: comprueba que el arreglo de entradas no incluya valores fuera del dominio. De lo contrario, NumPy devolverá resultados no válidos y una advertencia.
