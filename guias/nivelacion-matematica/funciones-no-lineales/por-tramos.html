Módulo 08

Funciones definidas por tramos.

Una función por tramos utiliza reglas distintas en diferentes partes del dominio. Es útil cuando una tarifa, condición o comportamiento cambia al atravesar un límite.

Cada entrada usa una sola regla

Consideremos una función que usa 2 − x cuando x < 1 y entrega 3 cuando x ≥ 1. Para evaluarla, primero ubicamos la entrada en su intervalo y solo después aplicamos la fórmula correspondiente.

EntradaCondición verdaderaResultado
x = 00 < 12 − 0 = 2
x = 11 ≥ 13
x = 44 ≥ 13
Atención al límite: los símbolos <, ≤, > y ≥ indican qué tramo incluye exactamente el punto de cambio. Dos reglas no deben disputarse la misma entrada ni dejarla sin respuesta.

Ejemplo: costo de alojamiento

Un hotel cobra $50 por noche durante las primeras tres noches. Desde la cuarta, mantiene los $150 iniciales y suma $35 por cada noche adicional.

C(n) = 50n si n ≤ 3;   C(n) = 150 + 35(n − 3) si n > 3n representa una cantidad entera y positiva de noches.
Python · código
import numpy as np

def costo_hotel(noches):
    return np.where(
        noches <= 3,
        50 * noches,
        150 + 35 * (noches - 3)
    )

noches = np.arange(1, 9)
print(costo_hotel(noches))

np.where(condición, valor_si_se_cumple, valor_si_no) permite aplicar las dos reglas a un arreglo completo, algo conveniente para graficar. Aquí no estamos estudiando condiciones de Python en profundidad: la condición solo selecciona el tramo matemático.

Continuidad y saltos

Algunas funciones por tramos se unen sin interrupción; otras presentan un salto en el límite. En el hotel, ambos tramos entregan $150 alrededor de las tres noches y el costo continúa desde allí. En una tarifa con cargo fijo nuevo, podría aparecer un salto.
