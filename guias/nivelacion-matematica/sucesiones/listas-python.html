Episodio 02 · Módulo 02

De la fórmula a la lista.

Usaremos la estructura del formulario: una lista vacía, un for que recorre las posiciones y append para guardar cada término.

La lista guarda lo que ya calculamos

sucesion = [] crea una lista vacía. Cada vez que ejecutamos sucesion.append(valor), agregamos ese valor al final. La fórmula genera el término y la lista lo conserva para consultarlo o sumarlo después.

En el formulario aparecía una lista con términos y luego se añadía siempre 6. Aquí comenzaremos vacíos y añadiremos el resultado de la fórmula. Así no mezclamos valores anteriores con los nuevos.

Matemática empieza en 1; el índice, en 0

Iteración iPosición n = i + 1Dónde se guarda
01sucesion[0]
12sucesion[1]
23sucesion[2]

i será el índice del resultado en nuestra lista. n será la posición de la sucesión matemática. Son números distintos: por eso el formulario usa n = i + 1.

Problema 1: los siete primeros términos

Queremos siete posiciones, desde n = 1 hasta n = 7. range(7) entrega los valores 0 a 6, no incluye 7. Al sumar uno obtenemos exactamente las posiciones pedidas.

Python · Primeros siete términos
sucesion = []
for i in range(7):
    n = i + 1
    sucesion.append(n**3 - 2)
    print(f'El término {n} es {sucesion[i]}')

Resultado esperado
El término 1 es -1
El término 2 es 6
El término 3 es 25
El término 4 es 62
El término 5 es 123
El término 6 es 214
El término 7 es 341

La sangría deja el cálculo, el guardado y el mensaje dentro del ciclo. Primero se añade el término y después se lee sucesion[i]. Si intentaras leerlo antes de añadirlo, esa posición todavía no existiría.

Lectura de una iteracióni = 2 → n = 3 → 3³ − 2 = 25 → sucesion[2] = 25

Cuatro términos después del vigésimo

«Los cuatro que continúan al vigésimo» significa a₂₁, a₂₂, a₂₃ y a₂₄. No incluye a₂₀. Necesitamos cuatro repeticiones, pero empezamos en n = 21.

Python · Posiciones 21 a 24
sucesion = []
for i in range(4):
    n = i + 21
    sucesion.append(n**3 - 2)
    print(f'El término {n} es {sucesion[i]}')

Resultado esperado
El término 21 es 9259
El término 22 es 10646
El término 23 es 12165
El término 24 es 13822

La lista tiene cuatro elementos, con índices 0 a 3. Aunque el primer resultado sea a₂₁, está guardado en sucesion[0], no en sucesion[21]. El índice depende de la lista que construimos, no del nombre del término.

Qué debes modificar en la plantilla

DatoPrimeros sieteCuatro después del 20
Cantidad de repeticionesrange(7)range(4)
Posición inicialn = i + 1n = i + 21
Término generaln**3 - 2n**3 - 2

En la actividad, range(24) genera desde a₁ hasta a₂₄. Incluye las posiciones de interés, pero no responde por separado a los dos tramos solicitados. Lo mismo ocurre con el range(50) del problema 3: hay que ajustar la cantidad.

Usar lo guardado

Python · Consultar una lista
sucesion = [3, 7, 11, 15]
print(sucesion[0])
print(len(sucesion))
print(sum(sucesion))

Resultado esperado
3
4
36

len cuenta elementos y sum suma sus valores. Sumar una lista no es lo mismo que pedir un término: aquí el cuarto término vale 15, pero la suma de los cuatro vale 36.

Ejecutar sin arrastrar resultados. Deja sucesion = [] en la misma celda que el ciclo. Al volver a ejecutarla, empezarás limpio; si ejecutas solo el for sobre una lista anterior, añadirás más datos.

Mini práctica

Adapta la estructura para obtener los cuatro primeros términos de bₙ = (8 − n)². Cambian la cantidad y la fórmula, no la lógica de guardar.

Ver la adaptación

Usa range(4), n = i + 1 y sucesion.append((8 - n)**2). Debes obtener [49, 36, 25, 16].

En estos ejemplos usamos for porque ya conocemos cuántos términos necesitamos. Python también puede recorrer directamente elementos de una lista; aquí nos interesa esta estructura concreta del formulario.
