Episodio 02 · Módulo 01

Un orden, una posición y un término.

Una sucesión organiza valores por posiciones. Primero entenderemos qué representa cada lugar y después llevaremos esa idea a una lista de Python.

Qué aprenderás en este episodio

En el episodio 1 trabajamos con funciones. Ahora la entrada será una posición: primera, segunda, tercera… A cada posición le corresponde un término. Aprenderemos a calcular términos, reconocer reglas aritméticas y geométricas, generar listas y decidir si un valor aparece en una sucesión.

El recorrido parte de los cuatro problemas iniciales de tu actividad: aₙ = n³ − 2 y bₙ = (8 − n)². Después subiremos a nivel medio con diferencias, razones, sumas y búsquedas que requieren revisar el comportamiento de la sucesión. No necesitaremos NumPy ni funciones definidas con def.

Piensa en una fila de casilleros numerados

Cada casillero tiene un número de posición y guarda un valor. El casillero 4 no tiene por qué guardar el número 4. Por ejemplo, en 3, 7, 11, 15, …, el cuarto casillero contiene 15. La posición es 4 y el término es 15.

Una sucesión puede tener una cantidad finita de términos o continuar indefinidamente. En Python normalmente guardaremos solo una parte finita: los siete primeros, por ejemplo. El orden importa y también pueden repetirse valores.

Cómo leer aₙ

aₙ se lee «a sub n» y representa el término que ocupa la posición n. El término general es una regla para calcularlo directamente. En este episodio tomaremos n = 1, 2, 3, …, salvo que el enunciado indique otro inicio.

Primer problema de la actividadaₙ = n³ − 2

Para el primer término sustituimos n por 1: a₁ = 1³ − 2 = −1. Para el cuarto: a₄ = 4³ − 2 = 62. No hace falta calcular todos los anteriores si ya conocemos la fórmula.

Python · Evaluar una posición
n = 4
termino = n**3 - 2
print(f'El término {n} es {termino}')

Resultado esperado
El término 4 es 62

Python escribe la potencia con **. n**3 significa n elevado a 3. No uses ^ para potencias: en Python tiene otro significado.

No todas las sucesiones crecen de la misma forma

Una lista corta no determina una única fórmula. Varias reglas pueden coincidir en los primeros valores y diferir después. Cuando el ejercicio pide reconocer un patrón, trabajamos con el tipo y la regla que propone el contexto.

La pregunta decide el procedimiento

«Calcula a₂₀» pide un valor de una posición conocida. «¿54870 pertenece?» pide buscar una posición que produzca ese valor. «Suma los primeros 10» pide combinar varios términos. Son tareas distintas, aunque todas usen el mismo término general.

Antes de seguir

Con aₙ = n³ − 2, calcula a₂ y a₃ a mano. Luego cambia n en el código y comprueba. Explica cuál es la posición y cuál es el valor que se obtiene.

Comprobar el ejemplo

a₂ = 6 y a₃ = 25. Las posiciones son 2 y 3; los términos correspondientes son 6 y 25.
