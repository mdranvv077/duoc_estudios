Construir un modelo lineal.

Cuando no conocemos la fórmula, podemos obtenerla desde puntos, una tabla o mediciones. El objetivo es determinar la pendiente m y el coeficiente de posición n.

Primero organiza los datos

Una tabla debe indicar qué variable corresponde a cada columna y qué unidades utiliza. Consideremos estos tiempos de transferencia:

Tamaño x (GB)Tiempo T(x) (min)
28
514
820

El tamaño es la variable independiente y el tiempo es la dependiente. Cada fila representa un punto: (2, 8), (5, 14) y (8, 20).

Método manual con dos puntos

  1. Calcula la pendiente con dos puntos: m = (14 − 8) / (5 − 2) = 2.
  2. Reemplaza un punto en y = mx + n.
  3. Despeja n: 8 = 2 · 2 + n, por lo tanto n = 4.
  4. Escribe el modelo completo.
T(x) = 2x + 4

Antes de aceptarlo, comprueba el tercer punto: T(8) = 2 · 8 + 4 = 20. El resultado coincide con la tabla.

Obtener el modelo con np.polyfit

Cuando existen varios datos, NumPy puede ajustar una recta. np.polyfit(x, y, 1) busca los coeficientes de un polinomio de grado 1, es decir, una expresión de la forma mx + n.

import numpy as np

x = np.array([2, 5, 8])
y = np.array([8, 14, 20])

m, n = np.polyfit(x, y, 1)

print(f"m = {m:.2f}")
print(f"n = {n:.2f}")
Python · resultadom = 2.00
n = 4.00

El formato :.2f muestra dos decimales para evitar una salida extensa causada por aproximaciones numéricas.

Datos exactos y datos medidos

Si todos los puntos pertenecen exactamente a una recta, el modelo pasa por cada uno. En mediciones reales puede haber pequeñas variaciones; en ese caso, polyfit construye la recta que mejor se ajusta al conjunto, pero no necesariamente coincide con todas las filas.

No aceptes la fórmula sin revisarla: interpreta m y n, evalúa algunos datos conocidos y observa el gráfico. Python encuentra coeficientes, pero tú debes confirmar que el modelo lineal sea apropiado para la situación.

Presentar el modelo completo

Una respuesta bien presentada incluye:

  • La función con nombres o símbolos claros.
  • Qué representa la entrada y su unidad.
  • Qué representa la salida y su unidad.
  • La interpretación de m y n.
  • El dominio donde se utilizará el modelo.
