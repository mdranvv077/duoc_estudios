Módulo 06

Evaluar y buscar entradas.

Una función lineal permite responder dos preguntas: qué salida corresponde a una entrada y qué entrada produce una salida determinada.

Calcular una salida conocida la entrada

Para el modelo T(x) = 2x + 4, queremos conocer el tiempo de una transferencia de 10 GB. Sustituimos x por 10.

EvaluaciónT(10) = 2 · 10 + 4 = 24

La conclusión es: según el modelo, transferir 10 GB tarda 24 minutos.

def tiempo(gigabytes):
    return 2 * gigabytes + 4

print(tiempo(10))
Python · resultado24

Encontrar la entrada desde una salida

Ahora queremos saber qué tamaño de archivo tarda 30 minutos. La salida es conocida y la entrada es la incógnita.

Ecuación2x + 4 = 30 → 2x = 26 → x = 13

El archivo tiene un tamaño de 13 GB. Podemos comprobarlo evaluando T(13) = 30.

Buscar el valor con fsolve

fsolve necesita una expresión que sea cero en la solución. Si la salida objetivo es 30, debemos resolver tiempo(x) − 30 = 0.

from scipy.optimize import fsolve

def tiempo(gigabytes):
    return 2 * gigabytes + 4

objetivo = 30
solucion = fsolve(lambda x: tiempo(x) - objetivo, 10)[0]

print(solucion)
Python · resultado13.0
Error frecuente: fsolve(tiempo, 10) buscaría cuándo el tiempo vale cero. Para buscar una salida específica, siempre resta el objetivo: tiempo(x) - objetivo.

Verificar el dominio y el tipo de variable

Una solución numérica no se acepta automáticamente. Si el problema limita los archivos entre 1 y 20 GB, 13 pertenece al dominio. Si la entrada representara personas o equipos, habría que comprobar además si debe ser un número entero.

No conviertas inmediatamente la solución con int(). Esa conversión elimina los decimales sin decidir si corresponde redondear, aproximar o rechazar el valor.

Respuesta completaSegún el modelo, una salida de [valor y unidad] se alcanza con una entrada de [valor y unidad], la cual pertenece al dominio estudiado.
