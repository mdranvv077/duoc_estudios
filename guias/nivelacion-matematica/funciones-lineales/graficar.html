Módulo 07

Graficar con Matplotlib.

Un gráfico permite observar la dirección, el punto inicial y el ritmo de cambio de una función. Debe respetar el contexto y comunicar claramente sus unidades.

Preparar las entradas y salidas

Continuaremos con T(x) = 2x + 4. Supongamos que el dominio contextual considera archivos desde 0 hasta 20 GB.

  1. np.linspace crea entradas distribuidas dentro del dominio.
  2. La función calcula una salida para cada entrada.
  3. plt.plot une los pares y dibuja la recta.
import numpy as np
import matplotlib.pyplot as plt

def tiempo(gigabytes):
    return 2 * gigabytes + 4

x = np.linspace(0, 20, 100)
y = tiempo(x)

plt.plot(x, y, label="T(x) = 2x + 4")
plt.xlabel("Tamaño del archivo (GB)")
plt.ylabel("Tiempo de transferencia (min)")
plt.title("Tiempo según el tamaño del archivo")
plt.grid()
plt.legend()
plt.show()

Leer el gráfico

  • El eje X muestra la variable independiente: tamaño en GB.
  • El eje Y muestra la variable dependiente: tiempo en minutos.
  • La recta sube porque la pendiente m = 2 es positiva.
  • La recta comienza en (0, 4) porque n = 4.
  • El punto (10, 24) representa una transferencia de 10 GB que tarda 24 minutos.

Destacar puntos importantes

plt.scatter permite marcar resultados que queremos explicar. Los puntos deben respetar el orden (entrada, salida).

# Agregar antes de plt.show()
plt.scatter([0, 10], [tiempo(0), tiempo(10)], color="red")
plt.annotate("Inicio: (0, 4)", (0, 4))
plt.annotate("10 GB: (10, 24)", (10, 24))

Usar límites coherentes

Si el ejercicio estudia de 0 a 20 GB, el gráfico no debe sugerir que el modelo fue validado para tamaños negativos o extremadamente grandes. Puedes fijar los límites visibles con:

plt.xlim(0, 20)
plt.ylim(0, 45)
El gráfico también es una respuesta: no basta con que aparezca una línea. Revisa el título, las variables, las unidades, el dominio y los puntos destacados antes de interpretarlo.

Errores frecuentes

  • Intercambiar x e y en plt.plot.
  • Olvidar ejecutar la celda de importaciones.
  • Escribir etiquetas sin unidades.
  • Crear un dominio que no corresponde al problema.
  • Modificar la fórmula, pero conservar un título o leyenda antigua.
