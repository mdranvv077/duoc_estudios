Módulo 01

¿Para qué sirven las funciones?

Una función permite describir cómo cambia un valor cuando cambia otro. No es solamente una fórmula: es una forma ordenada de representar una relación.

Antes de avanzar: aquí utilizaremos variables, operaciones y funciones sencillas de Python. No necesitas conocer condiciones ni ciclos. Si todavía no sabes leer esas bases, revisa primero estos módulos.

Una relación entre datos

Piensa en una aplicación de transporte. El precio final puede depender de la distancia recorrida; en un servidor, el consumo de memoria puede depender de la cantidad de usuarios; y en una descarga, el tiempo puede depender del tamaño del archivo.

En todos esos casos hay un dato que entregamos y otro que obtenemos. La función actúa como una regla: recibe una entrada, realiza una relación matemática y produce una salida.

Del problema a una respuesta

Trabajaremos con situaciones escritas en lenguaje cotidiano. Primero reconoceremos los datos y su significado; después usaremos una fórmula, una tabla, un gráfico o un fragmento de Python para analizarlos.

  1. Comprender qué situación se está describiendo.
  2. Reconocer qué valores cambian y cómo se relacionan.
  3. Calcular o representar la relación.
  4. Explicar el resultado usando el contexto original.
Idea importante: obtener un número no termina el ejercicio. También debemos decir qué representa, qué unidad utiliza y si tiene sentido dentro de la situación.

¿Por qué usaremos Python?

Python será una herramienta de apoyo. Nos ayudará a repetir cálculos, crear gráficos y aproximar soluciones que a mano serían más lentas. Sin embargo, el código no decide qué significa la respuesta: esa interpretación sigue siendo parte del trabajo matemático.

No necesitas dominar Python para comenzar. Usaremos plantillas breves y aprenderemos qué partes se conservan y cuáles se modifican según el problema.
