Módulo 03

Librerías y buenas prácticas.

Una librería agrega herramientas ya preparadas. En vez de programar todo desde cero, importamos las funciones que necesitaremos para calcular y graficar.

Las tres herramientas de la modalidad

  • NumPy ayuda a trabajar con números, rangos de valores y operaciones matemáticas.
  • Matplotlib permite representar funciones mediante gráficos.
  • fsolve, incluida en SciPy, aproxima el valor que resuelve una ecuación.
import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import fsolve

Primero las importaciones

En ejercicios de este tipo, una buena práctica es mantener las importaciones juntas en la primera celda de código. Cada vez que Colab se conecte a una máquina virtual nueva, ejecuta esa celda antes de usar cualquier plantilla.

Importar una librería no realiza el ejercicio ni crea un gráfico automáticamente. Solo deja sus herramientas disponibles para las celdas que vienen después.

Error común: si aparece un mensaje como np is not defined o plt is not defined, probablemente no ejecutaste la celda de importaciones o la sesión se reinició.

Orden recomendado del notebook

  1. Título y explicación breve del problema.
  2. Importación de librerías.
  3. Datos y definición de la función.
  4. Cálculo o gráfico.
  5. Interpretación del resultado con palabras y unidades.

Este orden permite volver al ejercicio después y entender qué se hizo sin tener que descifrar celdas dispersas.
