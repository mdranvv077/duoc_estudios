Módulo 02

Google Colab y sus archivos.

Google Colab permite escribir y ejecutar Python desde el navegador. Para esta modalidad será nuestro entorno principal.

Una máquina virtual en el navegador

Colab no ejecuta el código directamente en tu computador. Al iniciar una sesión, Google te presta temporalmente una máquina virtual: un computador remoto preparado para ejecutar Python y varias librerías científicas.

Esto evita instalar y configurar todo desde cero, permite trabajar desde equipos diferentes y reduce los problemas de compatibilidad. Solo necesitas un navegador, conexión a Internet y el notebook que quieras utilizar.

Antes de comenzar: presiona el botón Conectar en la esquina superior derecha y espera a que Colab termine de conectarse con la máquina virtual. Recién entonces ejecuta las celdas.

La sesión es temporal

La máquina virtual puede desconectarse después de un periodo sin actividad o al cerrar la sesión. Si eso ocurre, las variables y los archivos temporales cargados en ella pueden desaparecer.

  • Guarda el notebook en Google Drive o descárgalo.
  • Después de una reconexión, ejecuta nuevamente las celdas desde el inicio.
  • Ejecuta primero la celda que importa las librerías.

.ipynb y .py

En esta modalidad trabajaremos casi siempre con archivos .ipynb. Un notebook divide el trabajo en celdas: algunas contienen explicaciones y otras contienen código que puede ejecutarse por separado. Esto resulta cómodo para estudiar un problema paso a paso y mantener juntos el procedimiento, el gráfico y la interpretación.

Un archivo .py contiene un programa de Python más tradicional, normalmente ejecutado de principio a fin. También puede resolver los mismos ejercicios, pero para usarlo en Visual Studio Code debes tener Python y las librerías necesarias instaladas en el computador.

El orden de ejecución importa

Una celda puede utilizar datos creados en una celda anterior. Por eso, aunque Colab permite ejecutarlas en cualquier orden, conviene avanzar desde arriba hacia abajo. Si un resultado parece extraño, reinicia la sesión y ejecuta todo nuevamente desde el inicio.
