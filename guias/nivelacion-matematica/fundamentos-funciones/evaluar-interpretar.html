Módulo 06

Evaluar e interpretar.

Evaluar una función consiste en utilizar una entrada conocida para calcular su salida. Una pregunta inversa entrega la salida y pide encontrar la entrada.

Evaluar una función

Utilizaremos nuevamente el modelo de altura h(x) = (2/3)x + 48. Para calcular h(6), reemplazamos la variable x por 6 en toda la fórmula.

Sustituciónh(6) = (2/3) · 6 + 48 = 4 + 48 = 52

El cálculo produce 52, pero la respuesta todavía necesita contexto: cuando la edad es de 6 meses, la altura estimada por el modelo es de 52 centímetros.

No confundas los datos: 6 es una entrada medida en meses y 52 es una salida medida en centímetros. No representan la misma variable ni utilizan la misma unidad.

Evaluar con Python

def altura(meses):
    return (2 / 3) * meses + 48

altura_6_meses = altura(6)
print(altura_6_meses)
Python · resultado52.0

El decimal .0 no cambia el valor. Python lo muestra porque la división utilizada en la fórmula produce números de tipo float.

La pregunta en sentido inverso

Ahora conocemos la salida: queremos saber a qué edad el modelo estima una altura de 56 centímetros. La entrada x es la incógnita.

Ecuación que debemos resolver(2/3)x + 48 = 56

Restamos 48 a ambos lados y después dividimos por 2/3. El resultado es x = 12. La interpretación correcta es que el modelo estima una altura de 56 centímetros a los 12 meses.

Este tipo de ejercicio busca una entrada a partir de una salida conocida. No es lo mismo que evaluar directamente y todavía no necesitamos estudiar formalmente una función inversa.

Resolver la búsqueda con fsolve

fsolve busca el valor que hace que una expresión sea igual a cero. Por eso transformamos la pregunta en altura(x) - 56 = 0.

from scipy.optimize import fsolve

def altura(meses):
    return (2 / 3) * meses + 48

solucion = fsolve(lambda x: altura(x) - 56, 10)[0]
print(solucion)
Python · resultado12.0
  • 56 es la salida objetivo.
  • 10 es un valor inicial desde el cual fsolve comienza a buscar.
  • [0] extrae la primera solución entregada.
Error común: usar solamente fsolve(altura, 10) buscaría cuándo la altura vale cero, no cuándo vale 56. El objetivo debe restarse dentro de la expresión.

Comprobar e interpretar

Después de encontrar 12, reemplázalo nuevamente en la función: h(12) = 56. Luego confirma que 12 meses pertenece al dominio contextual de 0 a 24 meses.

Una respuesta completa debe indicar:

  1. El valor obtenido.
  2. La variable que representa.
  3. Su unidad.
  4. La entrada o salida con la que se relaciona.
  5. Si tiene sentido dentro del dominio del problema.
Conclusión completaSegún el modelo, el bebé alcanza una altura estimada de 56 centímetros a los 12 meses, valor que se encuentra dentro del periodo estudiado.
