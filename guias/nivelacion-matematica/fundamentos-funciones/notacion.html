Módulo 02

Cómo leer f(x).

La notación de una función identifica su nombre, el valor que recibe y la regla que produce el resultado.

Las partes de la notación

f(x) = 2x + 3
  • f es el nombre de la función. También podría llamarse A, C, altura o de otra forma.
  • x representa el valor de entrada.
  • 2x + 3 es la regla que se aplica a la entrada.
  • f(x) representa la salida obtenida después de aplicar la regla.
Importante: f(x) no significa f × x. Los paréntesis indican que la función f está recibiendo el valor x.

Definir no es lo mismo que evaluar

La expresión f(x) = 2x + 3 define la regla general. En cambio, f(4) pide utilizar 4 como entrada. Para calcularlo, sustituimos cada aparición de x por 4.

Evaluación paso a pasof(4) = 2 · 4 + 3 = 8 + 3 = 11

El resultado 11 es la salida asociada a la entrada 4. Su significado y sus unidades dependerán del problema que represente la función.

El nombre puede aportar contexto

Las letras cortas son habituales en matemáticas, pero en Python suele ser más claro utilizar nombres descriptivos. Ambas escrituras pueden representar exactamente la misma regla.

Notación matemáticaNombre descriptivo en Python
f(x)tiempo_transferencia(tamano)
A(l)area_cuadrado(lado)
C(u)costo(usuarios)

De la fórmula al código

def f(x):
    return 2 * x + 3

print(f(4))
Python · resultado11

Python necesita el símbolo * para escribir la multiplicación. Por eso, la expresión matemática 2x se escribe 2 * x en el código.
