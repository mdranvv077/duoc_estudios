Módulo 04

Dominio y contexto.

El dominio reúne los valores que una función acepta como entrada. En un problema aplicado, la situación puede limitar esos valores.

Dominio matemático

El dominio matemático se determina observando la fórmula. Pregunta qué números pueden reemplazar a la variable sin producir una operación imposible. Una función sencilla como f(x) = 2x + 3 acepta cualquier número real.

Otras expresiones pueden imponer restricciones. Por ejemplo, no se puede dividir por cero y, trabajando con números reales, no se puede calcular la raíz cuadrada de un número negativo.

Dominio contextualizado

El dominio contextualizado considera lo que representa la variable. La fórmula de crecimiento h(x) = (2/3)x + 48 acepta matemáticamente edades negativas o muy grandes, pero si fue creada para estudiar los primeros 24 meses de vida, esas entradas quedan fuera del problema.

Ejemplo contextualx representa la edad en meses y puede tomar valores desde 0 hasta 24.
Dominio contextual: 0 ≤ x ≤ 24

Los símbolos ≤ indican que 0 y 24 también están incluidos. La misma información puede escribirse como el intervalo [0, 24].

Valores continuos y discretos

También debemos decidir si la variable puede tomar valores intermedios.

Variable continuaPuede admitir decimales dentro de un intervalo, como tiempo, distancia, altura o temperatura.
Variable discretaSe cuenta mediante valores separados, normalmente enteros, como personas, equipos o campañas.

El tiempo puede ser 3,5 segundos, pero no puede haber 3,5 usuarios conectados. Aunque una fórmula entregue ese número, el contexto obliga a revisarlo o redondearlo de una forma justificada.

Preparar el dominio en Python

NumPy permite crear los valores de entrada que se usarán en un gráfico. La elección depende del tipo de variable.

# 100 valores entre 0 y 24 para una curva continua
meses = np.linspace(0, 24, 100)

# usuarios enteros desde 0 hasta 200
usuarios = np.arange(0, 201)

En arange, el límite final no se incluye. Por eso se escribe 201 cuando se quiere llegar hasta 200.

Qué revisar antes de responder

  • Qué representa la variable independiente.
  • Cuál es el mínimo y el máximo permitido.
  • Si los extremos están incluidos.
  • Si se aceptan decimales o solo números enteros.
  • Si la solución obtenida pertenece al dominio contextual.
No extiendas el modelo sin justificarlo: que Python pueda calcular una salida no significa que la función siga describiendo correctamente la realidad fuera del intervalo estudiado.
