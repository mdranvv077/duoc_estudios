¿Qué es una función?

Una función es una regla que relaciona valores: recibe una entrada y le asigna un único resultado como salida.

Entrada, regla y salida

Una función sirve para representar una relación de forma precisa. Podemos entregar el lado de un cuadrado como entrada y obtener su área como salida. La regla utilizada es elevar el lado al cuadrado.

Estructura fundamentalEntrada → regla de la función → salida
A(lado) = lado²

Si el lado mide 3 metros, la función entrega un área de 9 metros cuadrados. Si cambia la entrada, la misma regla permite calcular la salida correspondiente.

La condición que debe cumplir

Para que una relación sea una función, cada entrada permitida debe tener una sola salida. No tendría sentido que, usando exactamente la misma regla y el mismo lado de 3 metros, el área fuera 9 y 12 metros cuadrados al mismo tiempo.

Dos entradas diferentes sí pueden producir la misma salida. En la función que eleva un número al cuadrado, tanto 2 como −2 producen 4. Eso no rompe la definición porque cada entrada continúa teniendo un único resultado.

Sí es funciónCada entrada apunta a un solo resultado, aunque varias entradas puedan coincidir en la misma salida.
No es funciónUna misma entrada recibe dos resultados distintos dentro de la misma relación.

La función representa una situación

La entrada y la salida no siempre son números aislados. Pueden representar meses y altura, cantidad de usuarios y memoria utilizada, tamaño de un archivo y tiempo de transferencia, o años y valor de un equipo.

Por eso, antes de calcular conviene preguntar:

  • ¿Qué dato se entrega como entrada?
  • ¿Qué regla relaciona los datos?
  • ¿Qué resultado se obtiene y qué significa?
  • ¿Qué unidades acompañan a cada valor?

La misma idea en Python

Python permite escribir la regla mediante def. El valor recibido se llama parámetro y return devuelve la salida calculada.

def area_cuadrado(lado):
    return lado ** 2

print(area_cuadrado(3))
