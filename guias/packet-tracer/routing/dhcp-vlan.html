Módulo 04

DHCP por VLAN.

DHCP entrega direcciones IP automáticamente. Cada VLAN necesita un pool que corresponda exactamente con la red y gateway de su subinterfaz.

Antes de crear un pool

Excluye las direcciones reservadas para routers, switches, servidores u otros equipos con IP fija. Después crea un pool por VLAN con la red, máscara, gateway y DNS correctos.

Configurar pools de laboratorio

Router(config)# ip dhcp excluded-address 192.168.10.1 192.168.10.10 # reserva el gateway y direcciones fijas de VLAN 10
Router(config)# ip dhcp pool CIBERSEGURIDAD # crea el pool de VLAN 10
Router(dhcp-config)# network 192.168.10.0 255.255.255.0 # define la red que entregará
Router(dhcp-config)# default-router 192.168.10.1 # entrega el gateway de la VLAN
Router(dhcp-config)# dns-server 8.8.8.8 # entrega un DNS de ejemplo

Repite el mismo patrón para SERVIDORES con red 192.168.20.0/24 y gateway 192.168.20.1, y TIENDA con red 192.168.30.0/24 y gateway 192.168.30.1.

Resultado esperado: los PCs configurados para DHCP reciben una IP perteneciente a su propia VLAN, junto con el gateway correcto.
