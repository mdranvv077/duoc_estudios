Módulo 06

OSPF básico.

OSPF es un protocolo dinámico más escalable que RIP. En una práctica inicial se trabaja con una sola área: área 0.

Conceptos mínimos

Los routers OSPF forman vecinos por sus enlaces compartidos y anuncian redes mediante wildcards. El router ID identifica el proceso; debe ser único en cada router.

Configurar área 0

Router(config)# router ospf 1 # crea el proceso OSPF 1
Router(config-router)# router-id 1.1.1.1 # define un identificador único
Router(config-router)# network 10.0.0.0 0.0.0.3 area 0 # activa OSPF en el enlace entre routers
Router(config-router)# network 192.168.10.0 0.0.0.255 area 0 # anuncia la red de VLAN 10
Resultado esperado: cuando el router vecino tenga OSPF compatible en el mismo enlace y área, ambos formarán vecindad y compartirán sus rutas.
