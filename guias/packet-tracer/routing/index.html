Módulo 01

Antes de routing.

Routing permite que redes diferentes se comuniquen. Un router recibe un paquete, consulta su tabla de rutas y decide por qué interfaz enviarlo.

El problema que resuelve

Las VLANs separan la red en grupos. Esa separación es útil, pero también impide que un equipo de CIBERSEGURIDAD llegue directamente a uno de SERVIDORES o TIENDA. Para comunicar VLANs o redes remotas se necesita un gateway y una ruta válida.

La ruta de esta categoría

  • Router-on-a-Stick para comunicar VLANs mediante subinterfaces.
  • Rutas estáticas y una ruta por defecto para redes remotas.
  • DHCP por VLAN para entregar direcciones automáticamente.
  • RIPv2 y OSPF como introducción al routing dinámico.
Orden importante: configura primero VLANs y Trunking. Después crea los gateways de cada VLAN con Routing inter-VLAN. RIPv2 u OSPF se usan cuando existen varios routers.
