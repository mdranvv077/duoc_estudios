Módulo 07

Verificación y diagnóstico.

La verificación permite distinguir entre un error de VLAN, trunk, interfaz, gateway o tabla de rutas antes de cambiar comandos al azar.

Revisar paso a paso

Primero confirma que las interfaces y subinterfaces tengan IP. Luego revisa la tabla de rutas. Finalmente prueba conectividad desde el router y desde los PCs. Si usas RIP u OSPF, comprueba también su estado.

Comandos de diagnóstico

Router# show ip interface brief # revisa IP y estado de interfaces
Router# show ip route # muestra redes conectadas, estáticas o dinámicas
Router# show ip dhcp binding # muestra direcciones entregadas por DHCP
Router# show ip protocols # muestra el protocolo dinámico activo
Router# show ip ospf neighbor # revisa vecinos OSPF, si corresponde
Router# ping 192.168.20.1 # prueba alcance hacia otro gateway
Router# copy running-config startup-config # guarda al finalizar
Orden para resolver fallos: revisa primero cableado y estado de interfaces, luego VLAN y trunk, después gateways y finalmente las rutas. Cambia una cosa a la vez.
