Módulo 01

Entender Spanning Tree.

Spanning Tree Protocol, o STP, evita que el tráfico quede dando vueltas sin fin cuando hay varios caminos entre switches.

Imagina una red de carreteras

Piensa en los switches como cruces de carretera y en los cables como caminos. Tener dos caminos para llegar al mismo lugar es bueno: si uno se corta, todavía queda el otro. A esto se le llama redundancia o camino de respaldo.

El problema aparece si esos caminos forman un círculo y todos quedan abiertos. Sería como un automóvil que entra a una rotonda y nunca encuentra una salida. En la red, ciertos mensajes pueden pasar una y otra vez por los mismos switches. A esto se le llama bucle de capa 2.

Por qué un bucle es peligroso

Los switches transportan tramas, que son los mensajes que viajan dentro de una red local. Algunas tramas son de broadcast: se envían a todos los equipos. Si existe un bucle, pueden multiplicarse y ocupar la red hasta volverla muy lenta. Esto se conoce como tormenta de broadcast.

También pueden llegar varias copias del mismo mensaje y los switches pueden confundirse sobre el puerto donde se encuentra cada equipo. Por eso no conviene conectar switches formando un círculo sin la protección de STP.

Qué hace STP

STP actúa como un encargado del tránsito. Primero elige un Root Switch, que será el punto de referencia para los demás switches. Luego decide cuál es el mejor camino hacia él.

Si encuentra un camino repetido, deja uno de los puertos en espera. El cable no se desconecta: simplemente deja de transportar el tráfico normal. Si el camino principal falla, STP puede utilizar ese camino de respaldo. Es parecido a mantener una calle cerrada con una barrera y abrirla cuando la ruta principal deja de estar disponible.

Conceptos que debes reconocer

  • Root Switch: es el switch principal que STP utiliza como referencia para ordenar los caminos.
  • Root Port: es el puerto que ofrece el mejor camino desde un switch hacia el Root Switch. Cada switch que no sea el Root Switch tendrá uno.
  • Puerto designado: es el puerto autorizado para enviar tráfico por un tramo de la red.
  • Puerto alternativo: permanece como respaldo para evitar el bucle y puede utilizarse si el camino principal falla.

PVST y las VLANs

PVST crea un Spanning Tree separado para cada VLAN. Imagínalo como un mapa de caminos distinto para cada grupo de la red. Por eso SW1 puede ser el Root Switch de las VLANs 10 y 20, mientras SW2 puede serlo para las VLANs 30 y 40.

Idea principal: STP permite tener cables de respaldo entre switches sin que el tráfico quede atrapado en un círculo. No se utiliza para comunicar VLANs diferentes; esa tarea corresponde al routing.
