Lección 01

Antes de configurar.

Antes de escribir comandos, conviene entender qué equipo vas a administrar, qué deseas lograr y cómo reconocer una práctica terminada.

La idea de una práctica

En Packet Tracer se construye una red con dispositivos virtuales. Un router conecta redes distintas; un switch conecta equipos dentro de una misma red local. La configuración no se escribe al azar: cada comando cambia una parte concreta del comportamiento del dispositivo.

Para esta ruta usa un router, un computador conectado por consola y, más adelante, una red pequeña para probar conectividad. No necesitas memorizar todo de inmediato: primero identifica el objetivo, luego aplica la configuración y finalmente comprueba el resultado.

Aunque practicarás en Packet Tracer, la mayoría de los comandos y conceptos de esta guía también se aplican en dispositivos Cisco reales. El simulador permite aprender el procedimiento de forma segura; en equipos físicos pueden variar el modelo, los puertos disponibles o algunos detalles de la versión de IOS.

Antes de abrir la consola

  • Define un nombre sencillo para el equipo, por ejemplo R1.
  • Ten clara la red que usarás cuando asignes direcciones IP.
  • Guarda el archivo de Packet Tracer con frecuencia para no perder avances.
  • Usa solamente usuarios y contraseñas de ejemplo para laboratorios; nunca datos reales.
Cómo se trabajará aquí: cada lección explica primero qué problema resuelve. Después muestra la CLI con comentarios, y termina con una forma de comprobar que el cambio funcionó.
