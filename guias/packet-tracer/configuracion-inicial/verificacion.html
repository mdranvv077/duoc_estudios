Lección 07

Verificación y guardado.

Configurar no termina al presionar Enter. Debes comprobar el resultado y guardar la configuración para que sobreviva a un reinicio.

Dos configuraciones distintas

La running-config es lo que está funcionando ahora en la memoria del equipo. La startup-config es la copia que el router cargará al reiniciarse. Si no guardas, los cambios hechos durante la práctica desaparecen al apagar o reiniciar.

Los comandos de verificación no modifican nada: sirven para observar el estado de interfaces, SSH y la configuración actual antes de dar por terminada la actividad.

Comprobar antes de cerrar

Router# show ip interface brief # resume el estado e IP de las interfaces
Router# show running-config # muestra la configuración activa
Router# show ip ssh # comprueba el estado de SSH
Router# copy running-config startup-config # guarda la configuración para el reinicio
Resultado esperado: revisa que las interfaces activas estén up, que SSH esté habilitado y que el guardado termine sin errores antes de cerrar el archivo.
