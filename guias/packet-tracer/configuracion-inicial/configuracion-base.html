Lección 04

Configuración base.

Una configuración inicial ordenada identifica el equipo, evita búsquedas confusas y deja preparado el dispositivo para las siguientes prácticas.

Comandos esenciales

  • enable entra al modo privilegiado.
  • configure terminal abre la configuración global.
  • hostname R1 cambia el nombre del equipo.
  • no ip domain-lookup evita búsquedas DNS accidentales por errores al escribir.
  • copy running-config startup-config guarda la configuración.
Buenas prácticas: guarda al finalizar cada avance. Si cierras Packet Tracer sin guardar, perderás la configuración en ejecución.
