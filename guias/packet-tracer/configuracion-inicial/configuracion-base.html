Lección 04

Configuración base.

Una configuración inicial ordenada identifica el equipo, evita búsquedas confusas y deja preparado el dispositivo para las siguientes prácticas.

Comandos esenciales

Escribe esta configuración en el router o switch. Puedes cambiar R1 por el nombre que corresponda a tu topología.

Router> enable
Router# configure terminal
Router(config)# hostname R1
R1(config)# no ip domain-lookup
R1(config)# end
R1# copy running-config startup-config
Buenas prácticas: guarda al finalizar cada avance. Si cierras Packet Tracer sin guardar, perderás la configuración en ejecución.
