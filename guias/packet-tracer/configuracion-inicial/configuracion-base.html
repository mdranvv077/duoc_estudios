Lección 03

Configuración básica.

La primera configuración deja el equipo identificable, evita errores habituales al escribir y conserva tu avance para la siguiente sesión.

Qué vamos a resolver

Al comenzar una topología es fácil confundir los equipos si todos se llaman igual. Además, un comando incompleto puede hacer que el router intente buscar un nombre en DNS y parezca que quedó congelado. Esta sección prepara un punto de partida limpio para el resto del laboratorio.

El nombre del dispositivo debe representar su función dentro de la red. En esta guía se usará R1, pero puedes cambiarlo por uno que tenga sentido en tu topología.

Aplicar la configuración

Entra a la configuración global como aprendiste en la lección anterior y aplica los cambios. Lee el comentario verde de cada línea antes de presionar Enter.

Router> enable # habilita el modo privilegiado
Router# configure terminal # entra a la configuración global
Router(config)# hostname R1 # asigna un nombre al equipo
R1(config)# no ip domain-lookup # evita búsquedas DNS por errores al escribir
R1(config)# end # vuelve al modo privilegiado
R1# copy running-config startup-config # guarda la configuración actual
Resultado esperado: el prompt cambia a R1# y, al reiniciar el dispositivo, el nombre y los cambios guardados se mantienen.
