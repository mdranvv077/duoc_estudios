Lección 06

Dirección IP en interfaces.

Una interfaz de router necesita una dirección IPv4 y debe estar habilitada para poder comunicarse con los equipos de su red.

Qué representa una interfaz

Una interfaz es un puerto lógico o físico del router. Cada red conectada al router utiliza una interfaz distinta, y cada interfaz necesita una dirección IP que actúe como puerta de enlace para los dispositivos de esa red.

En este ejemplo, el router tendrá la dirección 192.168.10.1. Los equipos conectados a esa LAN podrán usarla como gateway predeterminado. Confirma primero el nombre exacto del puerto disponible en tu modelo de Packet Tracer.

Asignar dirección y habilitar el puerto

Router(config)# interface gigabitEthernet 0/0 # selecciona la interfaz a configurar
Router(config-if)# description LAN de usuarios # documenta el propósito del puerto
Router(config-if)# ip address 192.168.10.1 255.255.255.0 # asigna IP y máscara IPv4
Router(config-if)# no shutdown # habilita físicamente la interfaz
Resultado esperado: cuando el cable esté conectado y el otro extremo activo, la interfaz puede pasar a estado up/up. Según el modelo, el puerto puede llamarse GigabitEthernet o FastEthernet.
