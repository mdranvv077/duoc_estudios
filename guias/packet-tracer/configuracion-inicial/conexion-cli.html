Lección 03

Conexión y acceso CLI.

La interfaz de línea de comandos es donde se realizan las configuraciones Cisco. Puedes abrirla directamente desde el router o switch en Packet Tracer.

Primeros modos de trabajo

  • Router> es el modo de usuario: permite verificaciones básicas.
  • Router# es el modo privilegiado.
  • Router(config)# es el modo de configuración global.

Para pasar entre los primeros modos, utiliza esta secuencia:

Router> enable
Router# configure terminal
Router(config)#
Recuerda: el prompt te indica en qué modo estás. Antes de escribir un comando, revisa siempre el texto que aparece a la izquierda.
