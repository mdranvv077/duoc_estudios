Lección 02

Conocer la CLI.

La interfaz de línea de comandos es el lugar donde consultas el estado del equipo y aplicas cambios. Antes de configurar, aprende a leer el texto que aparece antes del cursor: ese texto se llama prompt.

¿Por qué hay distintos modos?

Cisco IOS separa los permisos para evitar cambios accidentales. Cada modo permite tareas distintas; por eso un comando puede funcionar en un prompt y fallar en otro. Leer el prompt antes de escribir es la forma más rápida de saber dónde estás.

  • Router> es el modo EXEC de usuario: permite consultas sencillas, pero no cambia la configuración.
  • Router# es el modo EXEC privilegiado: sirve para revisar, guardar y entrar a la configuración.
  • Router(config)# es la configuración global: aquí se ajustan opciones que afectan a todo el equipo.
  • Router(config-if)# es un submodo de interfaz: se usa para trabajar en un puerto específico.

Entrar sin cambiar nada todavía

La siguiente secuencia solo abre el nivel donde se preparan los cambios. Observa cómo cambia el prompt después de cada paso.

Router> enable # entra al modo privilegiado
Router# configure terminal # abre la configuración global
Router(config)# # listo para configurar el equipo
Recuerda: si el prompt no coincide con el que muestra la guía, no continúes todavía. Usa end para volver al modo privilegiado cuando sea necesario.
