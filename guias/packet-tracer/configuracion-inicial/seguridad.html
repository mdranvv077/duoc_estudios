Lección 04

Seguridad del dispositivo.

Antes de habilitar acceso remoto, protege los modos de administración y crea una cuenta local exclusiva para el laboratorio.

Qué se está protegiendo

Un router no solo reenvía tráfico: también puede ser administrado. La contraseña de modo privilegiado protege los cambios importantes; el usuario local identifica quién entra al equipo; y el banner comunica que el acceso es controlado.

En una práctica basta con credenciales de ejemplo. No copies contraseñas de clases, instituciones, trabajos o equipos reales: las siguientes son únicamente para este laboratorio.

Crear una base segura

Router> enable # entra al modo privilegiado
Router# configure terminal # abre la configuración global
Router(config)# enable secret GuiaEnable2026! # protege el modo privilegiado
Router(config)# service password-encryption # oculta contraseñas simples en la configuración
Router(config)# username guiaadmin secret GuiaLab2026! # crea un usuario local de laboratorio
Router(config)# banner motd # Acceso solo para laboratorio autorizado # # muestra un aviso al ingresar
Resultado esperado: el equipo tiene una clave para la administración, una cuenta local y un aviso visible al conectarse.
