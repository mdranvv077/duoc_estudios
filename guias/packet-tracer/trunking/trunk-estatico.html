Módulo 02

Trunk estático.

Un trunk estático es un enlace que se define manualmente para transportar varias VLANs entre equipos de red.

Qué significa que sea estático

Un switch puede intentar negociar automáticamente si un enlace debe ser trunk mediante DTP. En un trunk estático no se deja esa decisión al equipo: se indica expresamente que el puerto funcionará como trunk.

Esto hace que el diseño sea más predecible y evita que un puerto cambie de modo por negociación. A cambio, debes configurar los dos extremos correctamente: si solo un lado queda como trunk, el enlace no transportará las VLANs como esperas.

Elegir el enlace correcto

Identifica qué puerto conecta ambos switches. En este ejemplo se usará FastEthernet 0/1, pero debes reemplazarlo por el puerto real de tu topología. No configures como trunk un puerto conectado a un PC.

El comando switchport nonegotiate desactiva la negociación DTP. Úsalo cuando ambos extremos están configurados manualmente como trunk; si el otro lado depende de negociación automática, el enlace puede no levantarse como trunk.

Configurar ambos extremos

Aplica la misma base en Switch 1 y Switch 2, cambiando solo el nombre visible del prompt.

Switch(config)# interface fastEthernet 0/1 # selecciona el enlace entre switches
Switch(config-if)# switchport mode trunk # fuerza el puerto a funcionar como trunk
Switch(config-if)# switchport nonegotiate # desactiva la negociación automática DTP
Switch(config-if)# no shutdown # habilita el puerto si estaba apagado
Resultado esperado: el enlace físico queda preparado para transportar varias VLANs. Aún falta definir su VLAN nativa y cuáles VLANs estarán permitidas.
