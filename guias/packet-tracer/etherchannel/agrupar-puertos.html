Módulo 03

Agrupar los puertos físicos.

Ahora reuniremos FastEthernet 0/1 y 0/2 dentro del grupo 1 mediante PAgP: SW1 iniciará la negociación y SW2 responderá.

Punto de partida

La guía asume que ya conectaste dos switches 2960 utilizando dos cables: Fa0/1 con Fa0/1 y Fa0/2 con Fa0/2. También asumiremos que las VLANs 10, 20, 30, 40 y 99 ya existen en ambos equipos.

Si todavía no tienes esa base, puedes revisar:

VLANs Trunking Spanning Tree

Por qué usar interface range

interface range fastEthernet 0/1 - 2 selecciona Fa0/1 y Fa0/2 al mismo tiempo. Así ambos reciben exactamente las mismas instrucciones y disminuye la posibilidad de configurar uno de forma diferente por accidente.

Primero apagaremos temporalmente los puertos con shutdown. Esto permite preparar el grupo con calma y encender ambos enlaces cuando la configuración esté lista. La forma abreviada sh representa el mismo comando.

Configurar SW1 en desirable

SW1 será el lado que inicia la negociación. Al crear el grupo 1, IOS también crea la interfaz lógica Port-channel 1. 

SW1> enable # entra al modo privilegiado
SW1# configure terminal # abre la configuración global
SW1(config)# interface range fastEthernet 0/1 - 2 # selecciona los dos enlaces físicos
SW1(config-if-range)# shutdown # apaga ambos puertos mientras se preparan
SW1(config-if-range)# channel-protocol pagp # selecciona PAgP como protocolo
SW1(config-if-range)# channel-group 1 mode desirable # inicia la negociación del grupo 1
SW1(config-if-range)# no shutdown # enciende los dos enlaces
SW1(config-if-range)# exit # vuelve a la configuración global

Configurar SW2 en auto

En el segundo switch se seleccionan los mismos puertos y el mismo protocolo. El modo auto no inicia la conversación, pero responde a la propuesta enviada por SW1. 

SW2> enable # entra al modo privilegiado
SW2# configure terminal # abre la configuración global
SW2(config)# interface range fastEthernet 0/1 - 2 # selecciona los dos enlaces físicos
SW2(config-if-range)# shutdown # apaga ambos puertos mientras se preparan
SW2(config-if-range)# channel-protocol pagp # selecciona PAgP como protocolo
SW2(config-if-range)# channel-group 1 mode auto # espera y responde a la negociación
SW2(config-if-range)# no shutdown # enciende los dos enlaces
SW2(config-if-range)# exit # vuelve a la configuración global
Resultado esperado: Fa0/1 y Fa0/2 quedan asociados al grupo lógico 1. Todavía falta configurar el trunk sobre Port-channel 1; eso se realizará en el módulo siguiente.
