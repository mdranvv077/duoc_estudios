Módulo 02

Crear y nombrar VLANs.

Crear una VLAN en el switch solo define el grupo lógico. Todavía no mueve dispositivos: los puertos se asignarán en el módulo siguiente.

Planificar antes de escribir

Cada ID representa un grupo distinto. Los nombres no cambian el funcionamiento técnico, pero hacen que la configuración sea mucho más fácil de leer y mantener. En esta guía usaremos tres grupos de ejemplo: Ciberseguridad, Servidores y Tienda.

La VLAN 1 existe de fábrica. Para esta guía usaremos la VLAN 99 como VLAN nativa en los trunks más adelante. Es una decisión de esta práctica, no una regla universal: lo importante es no usar la VLAN 1 como nativa y no conectar usuarios a la VLAN nativa elegida.

Crear el catálogo de VLANs

Switch> enable # entra al modo privilegiado
Switch# configure terminal # abre la configuración global
Switch(config)# vlan 10 # crea o selecciona la VLAN 10
Switch(config-vlan)# name CIBERSEGURIDAD # asigna un nombre descriptivo
Switch(config-vlan)# exit # vuelve a configuración global
Switch(config)# vlan 20 # crea la VLAN de servidores
Switch(config-vlan)# name SERVIDORES # identifica la VLAN 20
Switch(config-vlan)# exit # vuelve a configuración global
Switch(config)# vlan 30 # crea la VLAN de tienda
Switch(config-vlan)# name TIENDA # identifica la VLAN 30
Switch(config-vlan)# exit # vuelve a configuración global
Switch(config)# vlan 99 # crea la VLAN nativa de esta guía
Switch(config-vlan)# name NATIVA_GUIA # la deja claramente identificada
Switch(config-vlan)# exit # vuelve a configuración global
Importante: la VLAN 99 se usará aquí como nativa solo para fines de guía. En una red real el número depende del estándar interno; debe permanecer sin puertos de usuarios.
