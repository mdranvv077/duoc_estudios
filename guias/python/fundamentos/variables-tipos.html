Módulo 02

Variables y datos.

Una variable es una caja con nombre: guarda un valor para consultarlo, mostrarlo o usarlo más adelante.

Guardar y reutilizar

edad = 18
edad_futura = edad + 1
print(f"El próximo año tendrás {edad_futura}")
Lectura natural: guarda 18 en edad; toma ese valor, súmale uno y guarda el resultado en otra caja llamada edad_futura.

Tipos que usarás al inicio

  • int: números enteros, como 6.
  • float: números decimales, como 3.14.
  • str: texto entre comillas.
  • bool: un valor True o False.
nombre = "Julio"
promedio = 6.4
activo = True
