Módulo 01

Antes de escribir Python.

Python se lee de arriba hacia abajo. Cada línea es una instrucción, y el orden cambia el resultado.

El código es una secuencia de ideas

Al empezar, no intentes memorizar todo. Lee cada línea como si fuera una oración corta: primero se guarda o calcula algo; después se muestra o se usa para tomar una decisión.

nombre = "Caroline"
print(f"Hola, {nombre}")
Lectura natural: guarda “Caroline” en una variable llamada nombre; luego muestra un saludo usando lo que quedó guardado.

La indentación también comunica

La sangría son los espacios al inicio de una línea. Python los usa para saber qué instrucciones pertenecen a una condición o función. Usa siempre cuatro espacios y no mezcles espacios con tabulaciones.

if edad >= 18:
    print("Puedes ingresar")

print("Fin del programa")
Fíjate: la línea con cuatro espacios pertenece al if. La última línea no tiene sangría, por eso se ejecuta siempre.
