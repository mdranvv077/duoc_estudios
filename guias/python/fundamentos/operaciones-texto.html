Módulo 03

Operaciones, texto y salida.

Python puede calcular con números y luego convertir ese resultado en un mensaje claro para quien usa el programa.

Operaciones básicas

Una operación toma números, los relaciona con un símbolo y devuelve un resultado. Empieza leyendo una línea a la vez: mira los números, identifica el símbolo y pregúntate qué resultado debería aparecer.

print(2 + 3)
print(8 - 3)
print(4 * 2)
print(10 / 2)
print(2 ** 3)
Lectura natural: muestra 5; luego muestra 5; después 8; después 5.0; y finalmente 8, porque 2 ** 3 significa “2 elevado a 3”.

Guardar un resultado simple

También puedes guardar el resultado en una variable. Así no necesitas volver a calcularlo si lo usarás después. El operador += es una forma corta de sumar algo a lo que ya estaba guardado.

vidas = 3
vidas += 1
print(vidas)
Lectura natural: guarda 3 en la caja llamada vidas; suma 1 a ese valor y vuelve a guardarlo. Al final muestra 4.

f-strings: texto que incorpora valores

La letra f antes de las comillas permite insertar una variable entre llaves. Así el mensaje se adapta sin tener que escribir cada valor manualmente.
