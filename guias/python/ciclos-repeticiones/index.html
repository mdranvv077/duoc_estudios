Módulo 01

Elegir entre for y while.

Ambos ciclos sirven para repetir instrucciones. La diferencia principal está en lo que conocemos antes de comenzar: un recorrido definido o una condición que debemos seguir comprobando.

Qué es un ciclo

Un ciclo evita escribir la misma instrucción una y otra vez. Python ejecuta el bloque indentado, vuelve al comienzo del ciclo y decide si corresponde realizar otra repetición.

Una analogía sencilla: for se parece a subir cinco escalones que ya puedes contar; while se parece a caminar mientras la puerta siga cerrada. En el primer caso conoces el recorrido. En el segundo, observas una condición.

for: un recorrido definido

En los ejemplos iniciales usaremos for junto con range(). Resulta apropiado cuando sabemos cuántas repeticiones necesitamos o qué números vamos a recorrer.

for repeticion in range(1, 4):
    print(f"Repetición {repeticion}")
Python · resultadoRepetición 1
Repetición 2
Repetición 3

El rango contiene los valores 1, 2 y 3. Por eso el bloque se ejecuta exactamente tres veces. Aquí no necesitamos crear un contador ni aumentarlo manualmente.

while: mientras algo sea verdadero

while evalúa una condición antes de cada vuelta. Si la condición es True, ejecuta el bloque y vuelve a comprobarla. Cuando se convierte en False, el ciclo termina.

clave = ""

while clave != "guia":
    clave = input("Escribe la clave: ")

print("Acceso permitido")

No sabemos si la persona acertará en el primer intento o después de varios. El ciclo continúa mientras la clave sea diferente de "guia" y termina cuando esa comparación deja de ser verdadera.

Importante: while no busca que la condición se vuelva verdadera para salir. Ocurre lo contrario: continúa mientras sea verdadera y normalmente termina cuando pasa a ser falsa. También puede finalizarse de forma explícita con break.

Comparación rápida

SituaciónCiclo recomendadoMotivo
Mostrar cinco ejercicios.forLa cantidad de repeticiones está definida.
Recorrer los números del 1 al 10.forEl recorrido está delimitado.
Volver a pedir una clave incorrecta.whileNo sabemos cuántos intentos serán necesarios.
Mantener un menú hasta elegir “salir”.whileLa repetición depende de una condición.

Los dos ciclos pueden resolver algunas tareas parecidas. Elegimos el que expresa la intención con mayor claridad: for para un recorrido definido y while para una repetición controlada por una condición.
