Módulo 01

Repetir con while.

while repite un bloque de instrucciones mientras una condición sea verdadera. Es útil cuando no sabes exactamente cuántas veces se repetirá algo, pero sí sabes cuándo debe terminar.

La idea: repetir mientras se cumpla algo

Lee while condicion: como: “mientras esta condición sea verdadera, vuelve a ejecutar las líneas indentadas”. Después de cada recorrido, Python regresa a la pregunta y decide si continúa o sale del ciclo.

Sirve para evitar escribir la misma instrucción muchas veces. En vez de copiar tres, diez o una cantidad desconocida de líneas, describes una regla: repite esta tarea mientras todavía haga falta. Por eso aparece en intentos de acceso, validación de formularios, menús simples o acciones que continúan mientras quede tiempo, saldo o energía.

Un ciclo while tiene tres piezas: una variable que representa el estado, una condición que pregunta si debe continuar y un bloque que hace el trabajo. Al terminar el bloque, Python vuelve a evaluar la condición. Si todavía es True, repite; si es False, continúa con la línea que está después del ciclo.

Cuándo elegirlo: usa while cuando sabes la condición de salida, pero no necesariamente el número exacto de repeticiones. Más adelante conocerás for, que resulta más cómodo cuando sí sabes cuántas veces repetir.

Contexto: imagina una persona que tiene tres intentos para ingresar un código. El programa debe mostrar el número de intento hasta que ya no queden. 

intento = 1 # comienza en el primer intento

while intento <= 3: # se repite mientras queden intentos
    print(f"Intento {intento}")
    intento += 1 # suma uno para acercarse al final
Lectura natural: empieza con el intento 1. Mientras el intento sea menor o igual a 3, muestra su número y luego le suma uno. Cuando llega a 4, la pregunta “¿4 es menor o igual a 3?” es falsa, así que el ciclo termina.

La variable debe cambiar

Un while necesita que algo cambie dentro del bloque. Si intento nunca aumentara, siempre valdría 1; la condición seguiría siendo verdadera y el ciclo no terminaría. A eso se le llama ciclo infinito.

Antes de ejecutar: identifica qué variable controla el ciclo y en qué línea cambia. Si no encuentras esa línea, probablemente el while no tiene una salida.

Repetir una pregunta hasta recibir un dato válido

while también sirve para validar entradas. En vez de terminar el programa por un dato incorrecto, puedes volver a preguntar hasta que la respuesta sea aceptable.

Contexto: una edad negativa no tiene sentido para este formulario. El programa insiste con la pregunta solo mientras el valor sea menor que cero. 

edad = int(input("Edad: "))

while edad < 0:
    print("La edad no puede ser negativa")
    edad = int(input("Escribe la edad nuevamente: ")) # vuelve a pedir el dato

print(f"Edad registrada: {edad}")
Lectura natural: pide una edad. Si es negativa, avisa el problema y pregunta otra vez. Cada nueva respuesta reemplaza el valor anterior de edad. Cuando se escribe un número válido, la condición deja de cumplirse y se registra la edad.

Cuándo usar while

  • Cuando una persona debe intentar una acción hasta cumplir una condición.
  • Cuando un dato necesita validarse antes de continuar.
  • Cuando una tarea sigue mientras haya saldo, tiempo, intentos o una opción activa.
Por ahora evita: while True. Puede ser útil más adelante, pero necesitas conocer una instrucción adicional para detenerlo de forma controlada.

Práctica

Crea un programa con una variable llamada energia que comience en 3. Mientras sea mayor que 0, muestra cuánta energía queda y réstale uno. Al finalizar, muestra “Energía agotada”. Léelo como una historia: hay energía, se usa una unidad y se vuelve a revisar si queda.
