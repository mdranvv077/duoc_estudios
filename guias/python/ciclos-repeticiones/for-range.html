Módulo 02

Repetir con for.

for repite un bloque una cantidad definida de veces. Es una forma clara de decir: “haz esta tarea para cada número que genere este rango”.

Cuándo elegir for

Usa for cuando ya sabes cuántas vueltas necesitas. Por ejemplo: mostrar tres intentos, realizar cinco preguntas o imprimir los números del 1 al 10. No necesitas aumentar una variable manualmente: Python avanza por el rango por ti.

Relación con while: while se repite mientras una condición sea verdadera; for se usa cuando ya tienes un recorrido definido. Ambos repiten instrucciones, pero responden a necesidades distintas.

El primer rango

range(1, 4) genera los números 1, 2 y 3. El primer número indica dónde comenzar; el segundo indica dónde detenerse, pero no se incluye. Por eso el 4 no aparece.

Contexto: un programa debe mostrar las tres rondas de una actividad. El número de la ronda cambia automáticamente en cada vuelta. 

for ronda in range(1, 4): # 1, 2 y 3
    print(f"Ronda {ronda}")
Lectura natural: para cada número desde 1 hasta antes de 4, guárdalo temporalmente en ronda y muestra ese número. Python hace tres vueltas: una con 1, otra con 2 y otra con 3.

Empezar desde cero

Si escribes solo range(3), Python comienza en 0. Eso genera 0, 1 y 2: tres números en total. Es normal verlo en código, aunque al empezar suele ser más legible indicar el inicio y el final de forma explícita. 

for numero in range(3):
    print(numero)
Lectura natural: repite tres veces. En la primera vuelta numero vale 0, luego vale 1 y finalmente vale 2.

Avanzar de cierto número en cierto número

range(inicio, fin, paso) permite indicar cuánto aumenta el contador en cada vuelta. El tercer valor es el salto entre un número y otro.

Contexto: una barra de progreso debe mostrar avances de 25 en 25 hasta llegar al 100 %. 

for progreso in range(0, 101, 25): # aumenta de 25 en 25
    print(f"{progreso}% completado")
Lectura natural: empieza en 0 y, en cada vuelta, suma 25. Como el final no se incluye, usamos 101 para que 100 sí aparezca. El resultado muestra 0 %, 25 %, 50 %, 75 % y 100 %.
Fíjate: el valor que cambia en un for —como ronda o progreso— lo actualiza Python. No necesitas escribir += 1 dentro del bloque.

Práctica

Haz un programa que muestre cinco mensajes: “Ejercicio 1 listo”, “Ejercicio 2 listo” y así hasta el 5. Usa una variable llamada ejercicio y range(1, 6). Luego cambia el rango para que muestre solo los números pares entre 2 y 10.
