Módulo 03

Más de un camino.

if prueba la primera condición; elif plantea otra si la primera falló; else se encarga de cualquier caso que quedó fuera.

Una sola respuesta por recorrido

Python revisa esta estructura de arriba hacia abajo. Apenas encuentra una condición verdadera, ejecuta ese bloque y no continúa preguntando por los elif siguientes.

temperatura = 18 # valor que vamos evaluar

if temperatura >= 30: # primero revisa el caso de calor
    print("Hace calor")
elif temperatura >= 15: # solo se evalúa si el if anterior falló
    print("La temperatura es agradable")
else: # cualquier valor que no cumplió antes
    print("Hace frío")
Lectura natural: 18 no llega a 30, así que Python pasa a la siguiente pregunta. Sí es mayor o igual a 15, entonces muestra “La temperatura es agradable” y termina esta decisión.

El orden importa

Coloca primero los casos más específicos. Si escribieras una condición muy amplia antes, podría capturar un caso que querías resolver después. else no lleva condición: significa literalmente “en cualquier otro caso”.

Buena práctica: no uses else por costumbre. Úsalo cuando realmente exista una respuesta útil para todos los casos restantes.
