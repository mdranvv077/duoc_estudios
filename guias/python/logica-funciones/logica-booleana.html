Módulo 04

Unir preguntas lógicas.

A veces una sola comparación no basta. and, or y not permiten construir preguntas más completas sin perder claridad.

Qué significa cada palabra

  • and: ambas condiciones deben ser verdaderas.
  • or: basta con que una condición sea verdadera.
  • not: invierte una respuesta booleana.
  • is e is not: comprueban identidad; al inicio úsalos especialmente con None.
tiene_entrada = True
es_invitado = False

if tiene_entrada and not es_invitado:
    print("Acceso autorizado")
Lectura natural: si tiene entrada es verdadero y además no es invitado, muestra el acceso autorizado. not False se interpreta como verdadero.

Cuándo usar is

== compara valores; is pregunta si se trata del mismo objeto. Para empezar, la forma más clara y común es dato is None: comprueba si una variable todavía no tiene información asignada.

Regla simple: para números y texto, normalmente usa ==. Reserva is para None hasta que conozcas con más profundidad los objetos de Python.
