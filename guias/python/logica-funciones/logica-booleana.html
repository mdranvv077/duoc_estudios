Módulo 04

Condiciones combinadas.

A veces una condición necesita revisar más de una cosa. Las palabras and, or y not unen o modifican respuestas de True y False.

and: ambas deben cumplirse

and exige que las dos partes sean verdaderas. Si una sola falla, el if completo es falso y no ejecuta su bloque. 

tiene_entrada = True
tiene_identificacion = True

if tiene_entrada and tiene_identificacion: # las dos son necesarias
    print("Acceso autorizado")
Lectura natural: si la persona tiene entrada y tiene identificación, muestra “Acceso autorizado”. Aquí las dos variables guardan True, así que la condición queda como True and True. Como ambas partes se cumplen, Python muestra el mensaje.

or: basta con una

or solo necesita una parte verdadera. Falla únicamente cuando las dos partes son falsas. 

tiene_clave = False
tiene_tarjeta = True

if tiene_clave or tiene_tarjeta:
    print("Puede iniciar")
Lectura natural: no tiene clave, pero sí tarjeta. False or True da True, por eso Python permite iniciar.

not: invertir una respuesta

not cambia True por False, y False por True. 

cuenta_bloqueada = False

if not cuenta_bloqueada:
    print("Acceso disponible")
Lectura natural: la cuenta no está bloqueada, porque su valor es False. Al escribir not cuenta_bloqueada, la condición pasa a ser verdadera y se muestra el acceso.

is e is not con None

Para empezar, úsalos para comprobar si una variable todavía no tiene información. None significa “por ahora, no hay valor”. 

codigo = None

if codigo is None:
    print("Aún no se ingresó un código")

codigo = "A123"
if codigo is not None:
    print("Código recibido")
Lectura natural: primero codigo guarda None, por eso se avisa que falta el dato. Luego guarda “A123”; ahora ya no es None, así que se confirma que el código fue recibido.
Regla simple: para comparar números o texto usa normalmente ==. Por ahora, reserva is e is not para None.
