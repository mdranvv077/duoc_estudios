Módulo 04

Unir preguntas lógicas.

A veces una condición necesita revisar más de una cosa. Las palabras and, or y not unen o modifican respuestas de True y False.

and: esto y esto otro

and exige que las dos partes sean verdaderas. Si una sola falla, todo el if se considera falso y el bloque no se ejecuta.

tiene_entrada = True
es_invitado = False

if tiene_entrada and not es_invitado: # deben cumplirse ambas partes
    print("Acceso autorizado")
Lectura natural: si la persona tiene entrada y no es invitada, muestra “Acceso autorizado”. En este ejemplo, tiene_entrada es True. es_invitado es False, pero not lo convierte en “no es invitada”, que es True. Queda True and True, por eso permite el acceso.

or: esto o esto otro

or es menos exigente: basta con que una de las dos partes sea verdadera. Solo falla cuando ambas son falsas.

tiene_clave = False
tiene_tarjeta = True

if tiene_clave or tiene_tarjeta: # basta con una forma de acceso
    print("Puede iniciar")
Lectura natural: si tiene clave o tiene tarjeta, puede iniciar. No tiene clave, pero sí tarjeta: False or True da True, así que Python muestra el mensaje.

not: cambiar la respuesta

not invierte un valor booleano. Es útil cuando una variable se entiende mejor en negativo, por ejemplo, “la cuenta no está bloqueada”.

cuenta_bloqueada = False

if not cuenta_bloqueada: # no está bloqueada
    print("Acceso disponible")
Lectura natural: cuenta_bloqueada vale False, es decir, la cuenta no está bloqueada. not False se transforma en True, por eso se muestra “Acceso disponible”.

is e is not con None

Al empezar, usa is e is not para comprobar si una variable todavía no tiene un dato. None significa “por ahora, no hay valor”.

codigo = None

if codigo is None:
    print("Aún no se ingresó un código")

codigo = "A123"
if codigo is not None:
    print("Código recibido")
Lectura natural: al inicio, codigo no tiene un valor y guarda None; por eso el primer if se cumple. Luego se guarda “A123”. Ahora codigo is not None significa “el código ya tiene algún valor”, por eso se muestra “Código recibido”.
Regla simple: para comparar números o texto normalmente usa ==. Por ahora, reserva is e is not para None.
