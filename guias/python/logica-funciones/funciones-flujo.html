Módulo 05

Funciones y control del flujo.

Una función reúne instrucciones bajo un nombre. Con def puedes crear una acción reutilizable; con exit(), terminar el programa cuando ya no tiene sentido continuar.

Crear una acción con nombre

Piensa en una función como una receta con título. La defines una vez y la llamas cada vez que necesitas repetir esa tarea. El código dentro también usa sangría, porque pertenece a la función. 

def saludar(nombre):
    print(f"Hola, {nombre}")

saludar("Caroline")
Lectura natural: crea una acción llamada saludar que recibe un nombre y muestra un saludo. Al final, llama esa acción usando “Caroline”. Definirla no la ejecuta: la ejecución ocurre al llamarla.

Detener una interacción incorrecta

exit() es útil cuando una respuesta impide que el programa siga de forma válida. Por ejemplo, si pides una edad y llega un número negativo, puedes mostrar el problema y terminar antes de hacer cálculos absurdos. 

edad = int(input("Edad: "))
if edad < 0:
    print("La edad no puede ser negativa")
    exit()

print("Dato válido")
Lectura natural: si la edad es negativa, informa el error y termina. Por eso “Dato válido” solo aparece cuando la edad permite continuar.

Práctica final de la categoría

Crea una función llamada revisar_nota que reciba una nota. Si está fuera del rango de 1.0 a 7.0, muestra un mensaje y usa exit(). Si es válida, usa if, elif y else para indicar si está reprobada, aprobada o destacada.
