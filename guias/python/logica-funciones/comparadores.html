Módulo 02

Comparar valores.

Los comparadores producen un valor booleano: True si la comparación se cumple o False si no. Son las preguntas que usa un if.

Las preguntas más comunes

  • == pregunta si dos valores son iguales.
  • != pregunta si son distintos.
  • >= y <= incluyen el límite.
  • > y < comparan sin incluirlo.
nota = 5.5
aprobado = nota >= 4.0
print(aprobado)
Lectura natural: pregunta si la nota 5.5 es mayor o igual a 4.0. La respuesta se guarda en la caja aprobado, que contiene True.

Igualar no es comparar

Un solo signo = guarda un valor. Dos signos == hacen una pregunta. Es una diferencia pequeña al escribir, pero cambia por completo lo que el programa hace.

Prueba mental: antes de ejecutar un comparador, responde tú mismo la pregunta. Eso te ayuda a anticipar si Python obtendrá True o False.
