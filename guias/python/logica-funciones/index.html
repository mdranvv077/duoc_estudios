Módulo 01

Decisiones y condiciones.

Una condición hace una pregunta. Si la respuesta es verdadera, Python ejecuta las líneas indentadas debajo; si no, las omite o busca otro camino.

Un programa no siempre hace lo mismo

Hasta ahora las instrucciones se ejecutaban una tras otra. Con una condición, el programa puede reaccionar a un dato: una edad, una nota o un estado. Lee if como “si ocurre esto, haz lo siguiente”.

edad = 17

if edad >= 18:
    print("Puedes ingresar")
Lectura natural: guarda 17 en edad. Después pregunta: “¿edad es mayor o igual que 18?”. Como no lo es, la línea con sangría no se ejecuta.

La sangría forma el bloque

Los cuatro espacios antes de print() indican que esa instrucción pertenece al if. El signo : anuncia que comienza un bloque. Sin una sangría correcta, Python no sabrá qué debe ocurrir cuando la condición se cumple.

Idea clave: una condición no cambia un valor por sí sola. Solo decide si ciertas instrucciones se ejecutan o no.
