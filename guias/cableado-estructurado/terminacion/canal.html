Canal y enlace permanente.

El enlace permanente considera el cableado fijo entre las terminaciones del panel y la toma. El canal agrega los cordones de ambos lados. Esta distinción evita atribuir a la instalación fija un problema causado por un patch cord.

Límites de cada medición

El enlace permanente considera el cableado fijo entre las terminaciones del panel y la toma. El canal agrega los cordones de ambos lados. Esta distinción evita atribuir a la instalación fija un problema causado por un patch cord.

Recorrido lógico

Switch → patch cord → patch panel → cable horizontal → keystone/faceplate → cordón de usuario → equipo. Selecciona en el modelo cada tramo y observa cuáles pertenecen al enlace permanente.

Diagnóstico por sustitución

Si un canal falla, prueba primero cordones y puertos accesibles. Si el enlace permanente falla, revisa terminaciones, pares, recorrido y daño físico antes de reemplazar todo el cable.
