# Archivos de la modalidad Enlaces PtP

Deja los archivos en estas subcarpetas:

- google-earth-pro/: paquete de Google Earth Pro que se usará en la guía.
- radio-mobile/: paquete de Radio Mobile y sus componentes necesarios.
- materiales/: archivos del taller, por ejemplo rutas KML/KMZ o fichas.

No hay instalador de Ubiquiti: se utiliza https://ispdesign.ui.com/.

## Habilitar una descarga

Archivos incorporados el 27 de octubre de 2026:

- google-earth-pro/GoogleEarthProSetup.exe (13 283 768 bytes).
- radio-mobile/Radio_Mobile_Setup.exe (4 110 722 bytes).

Se movieron desde Descargas y se verificó su integridad con SHA-256.
No se ejecutaron. La versión final de las aplicaciones no se ha verificado:
la versión del instalador puede ser distinta de la del programa que instala.

Para cambiar o incorporar otros archivos, editar catalogo.json:

1. En file, indicar la ruta relativa, por ejemplo google-earth-pro/ARCHIVO_REAL.exe.
2. Indicar version, size y date según el archivo real. No confundir la fecha de incorporación con la del proveedor.
3. Mantener file en null mientras no exista el paquete.
4. Comprobar compatibilidad, procedencia y condiciones de redistribución antes de publicarlo.
5. Publicar los archivos y catalogo.json juntos en main. El botón descarga desde raw.githubusercontent.com.

La página comprueba que el archivo registrado exista antes de activar el enlace.
Para actualizar un paquete, actualizar también sus datos. Los enlaces oficiales
permanecen debajo de cada descarga para consultar lo que ofrezca el proveedor.

Revisar los límites de tamaño de GitHub antes de incorporar paquetes grandes.
No subir credenciales, coordenadas privadas o proyectos de terceros sin permiso.
No se han descargado ni ejecutado programas para preparar esta carpeta.
