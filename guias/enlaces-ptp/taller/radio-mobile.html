Módulo 03

Evaluar con Radio Mobile.

Usar las mismas ubicaciones y documentar las hipótesis del modelo.

Preparar el programa y los datos

Utiliza el paquete que incorporemos a la guía o consulta las descargas oficiales del autor. Comprueba que los componentes necesarios estén juntos y que exista información de elevación para el área. Una pantalla sin relieve no demuestra que el terreno sea plano.

Configurar el sistema

  1. Crea las unidades de los extremos A y B con sus coordenadas.
  2. Asigna las alturas de antena sobre el terreno con la referencia correcta.
  3. Prepara el sistema de radio: frecuencia, TX, ganancias, pérdidas y umbral de recepción si corresponde.
  4. Relaciona las unidades en la red o enlace de análisis y revisa el perfil.
  5. Anota las hipótesis de terreno, entorno y parámetros estadísticos utilizados.

Las etiquetas de menús dependen de la versión y el idioma del paquete que dejes. Ajustaremos las instrucciones exactas a ese archivo; no vamos a mezclar capturas de versiones distintas sin avisarlo.

Comparar, no copiar un indicador

Observa pérdidas, nivel recibido y despeje según el análisis disponible. Conserva una captura con los parámetros de entrada y otra con el resultado. Si no tienes un modelo del equipo Ubiquiti, utiliza parámetros equivalentes de su ficha y escribe que es una aproximación, no una integración automática.

Mismo caso. No cambies alturas o potencia para obtener una predicción favorable y luego compares el resultado con una plataforma donde no aplicaste esos cambios.
