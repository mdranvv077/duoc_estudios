Capítulo 02 · Módulo 02

Guardar y retomar el proyecto.

Conservar los puntos, la vista geográfica y la factibilidad editable para continuar otro día.

Qué tenemos que guardar

Ya exportamos el enlace y lo vimos en Earth Pro. Ahora guardaremos la carpeta con los marcadores y el enlace para volver a visualizarlo, y el proyecto de Radio Mobile para seguir modificando y calculando la factibilidad.

ArchivoQué conserva
.kmz / .kml · Google Earth ProMarcadores, carpetas y geometría del enlace. KMZ permite reunir el contenido en un archivo comprimido.
.net · Radio MobileRedes, unidades, sistemas, roles y parámetros de la simulación, con sus referencias a mapas e imágenes asociados.
.map · Radio MobileMatriz de elevaciones del terreno utilizada en el proyecto.
.bmp / .jpg · imágenes del mapaLa representación visual del mapa. No reemplaza el terreno .map ni la configuración .net.

1. Reunir los puntos y el enlace en Google Earth Pro

  1. En el panel Lugares, haz clic derecho sobre Mis lugares → Añadir → Carpeta.
  2. Escribe PtP Sombrero–Codigua y confirma con Aceptar.
  3. Arrastra dentro los marcadores originales Cerro Sombrero y Codigua.
  4. Desde Lugares temporales, arrastra también la entrada completa importada desde Radio Mobile. Conserva su contenido interno, no solo una de sus líneas.
  5. Despliega la carpeta y comprueba que contenga los dos marcadores iniciales y el enlace importado. Activa sus casillas para verlos.

Así queda una carpeta del caso bajo Mis lugares. Los marcadores iniciales y los sitios incluidos en la exportación pueden mostrar nombres repetidos: forman parte de elementos distintos. Puedes desmarcar los que estorben visualmente sin borrarlos.

2. Guardar una copia KMZ en Descargas

  1. Haz clic derecho sobre la carpeta PtP Sombrero–Codigua, no sobre uno de sus puntos.
  2. Selecciona Guardar lugar como… (Save Place As…, si la interfaz está en inglés).
  3. Elige Descargas y crea una carpeta llamada PtP-Sombrero-Codigua.
  4. Usa el nombre PtP-Sombrero-Codigua.kmz, selecciona el tipo KMZ y pulsa Guardar.

Guardar la carpeta incluye sus elementos. Si guardas únicamente Cerro Sombrero, ese archivo no contendrá automáticamente Codigua ni el enlace. Conserva también el profile4.kml original que salió de Radio Mobile.

Una copia que puedes llevarte. El KMZ permite abrir el caso en otro momento o en otro equipo con Earth Pro. Si después cambias los marcadores o el contenido de la carpeta, repite Guardar lugar como… para actualizar esa copia.

3. Volver a abrirlo en Google Earth Pro

Usa Archivo → Abrir, selecciona PtP-Sombrero-Codigua.kmz y pulsa Abrir. La carpeta importada aparecerá en Lugares temporales; puedes arrastrarla a Mis lugares si quieres conservarla en esa instalación.

Expándela, activa los puntos y la traza y haz doble clic sobre el enlace para localizarlo. Si ya tienes el caso abierto, evita cargar otra copia encima al comprobar el archivo.

El guardado conserva las referencias de altitud de los elementos. Mantén los marcadores iniciales relativos al suelo y la geometría exportada de Radio Mobile con su referencia absoluta, como se explicó en el módulo anterior.

4. Guardar la factibilidad en Radio Mobile

Regresa a la ventana principal de Radio Mobile. Estas opciones están en su menú File; el menú Edit de Radio Link se utilizó para exportar el perfil.

Primero: el terreno y sus imágenes

  1. Abre File → Save map as… y guarda el terreno como Sombrero-Codigua.map dentro de la carpeta del caso.
  2. Con la imagen de mapa correspondiente activa, usa File → Save picture as… y guarda, por ejemplo, Sombrero-Codigua.bmp, con el formato elegido en el diálogo.
  3. Si utilizaste más de una imagen de mapa y quieres recuperarlas, repite el guardado para cada una con nombres distintos.

Después: la red y sus archivos asociados

  1. Selecciona File → Save networks as….
  2. Elige la misma carpeta y guarda como Sombrero-Codigua.net. Aquí se conserva la configuración de redes, unidades y sistemas.
  3. Usa File → Save networks. Si aparece el cuadro Save Networks con los archivos relacionados, incluye el mapa y las imágenes de este caso y confirma el guardado. Si alguno aún no tiene nombre, guárdalo cuando se solicite.

Guardar primero el terreno y las imágenes facilita que la red quede vinculada a archivos ya nombrados. Conserva juntos el .net, el .map y las imágenes; una captura de Radio Link o el KML exportado no permiten recuperar por sí solos los parámetros editables.

Guardar cambios posteriores. Usa File → Save networks para actualizar la red. Si también modificaste el terreno o una imagen, guarda esos archivos. Para una variante del diseño, utiliza Save networks as… con otro nombre y conserva los archivos de mapa que esa variante necesite.

5. Reabrir y comprobar la factibilidad

  1. Una vez guardado el trabajo, abre Radio Mobile en la próxima sesión y selecciona File → Open networks.
  2. Abre Sombrero-Codigua.net. Comprueba si se recuperaron también el mapa y las imágenes asociados.
  3. Si no aparecen, utiliza File → Open map para el .map y File → Open picture para las imágenes guardadas. Esto puede ser necesario si moviste la carpeta o cambiaste rutas.
  4. Revisa las unidades y sus coordenadas, la red PtP Sombrero–Codigua, sus parámetros, Systems y Membership.
  5. Vuelve a abrir Radio Link y comprueba el resultado en ambos sentidos con Swap.

Para este escenario, la referencia es 5800 MHz, 21 dBm, 30 dBi y 15 m por extremo; con el umbral de −75 dBm, se obtuvo Rx level = −59,8 dBm y Rx Relative = 15,2 dB. Si algo cambia al abrirlo, revisa que cargaste los mismos perfiles, ubicaciones y terreno.

Para trasladar el trabajo a otro computador, copia toda la carpeta y conserva también los patrones de antena utilizados, en este caso Corner.ant. El otro equipo debe disponer de ese patrón y de los datos de elevación si necesita recalcular o ampliar el terreno.

Antes de darlo por guardado

  • Earth Pro: el KMZ abre la carpeta con los puntos y el enlace completo.
  • Radio Mobile: el NET abre la red y puedes recuperar su terreno e imágenes.
  • Documentación: conserva las capturas de Radio Link y Earth Pro y la ficha de parámetros del mismo escenario.

Consulta de apoyo: Google Earth · guardar una carpeta como KMZ.
