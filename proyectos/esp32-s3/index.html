La idea

Un pequeño laboratorio flexible

La ESP32-S3 funcionará como una plataforma para aprender y probar. La intención no es limitarla a una sola tarea: podrá ejecutar código en Python, conectarse mediante WiFi y recibir sensores según lo que necesite cada experimento.

Una prueba diferente

Linux dentro de la ESP32-S3

También instalé Linux tomando como referencia el proyecto Linux-on-esp32-S3. Esta implementación ejecuta Linux de forma nativa en la arquitectura Xtensa y combina el sistema con el firmware de Espressif encargado de funciones como WiFi y acceso a la memoria flash.

Es un entorno reducido: incluye MicroPython y herramientas útiles, pero conserva las limitaciones normales de memoria y potencia de una placa de este tamaño.

Interfaz propia

Un panel web al estilo de un router

Preparé una web personalizada para administrar lo básico desde el navegador y consultar rápidamente el estado del dispositivo. La idea es tener un punto de control sencillo, parecido al panel de un router, sin depender siempre de la consola serial.
